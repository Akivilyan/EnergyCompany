# 游戏核心设计 · 整合摘要（速览）

> 本文为 [`game-core-design.md`](./game-core-design.md) 的**整合骨架摘要**，便于在不通读全文的情况下把握核心玩法与系统结构；细节与定稿以原文为准。  
> 历次设计稿修订的要点与动因见 [`game-core-design-设计演变摘要.md`](./game-core-design-设计演变摘要.md)。

---

## 文档定位与平台

- **范围**：玩法与系统设计，不涉及技术实现。
- **平台**：当前优先微信小游戏；PC 可在同一骨架上增复杂度。
- **名称**：游戏名与公司名不写死，以最新命名为准。

## 设计支柱与原则

- **类型**：轻策略经营；题材为能源建设与区域供能；**静态操作 + 按月推进**。
- **边界收紧**：宁可略平淡也不堆复杂度；**不做成就**、**不做竞争公司与区域争夺**、**不做抽卡与多档礼包**。
- **保留骨架**：选区（随等级解锁可经营区）、建设、科技、借贷收购、区域/主干电网、**事件**（资金/收入/研发节奏）、资金与社会价值。
- **目标**：每月有明确决策、阶段目标清晰、建设/节点/事件带来节奏感、复杂度可控。

## 界面结构（四层）

| 层级 | 职责要点 |
|------|-----------|
| **地区主界面** | 最常停留：建设发电与区域电网、在建与工期、供能满足率、运营；顶栏资金/社会价值/年月；`下一月` 主按钮 |
| **全国大地图** | 选区（未解锁灰显）、标签、大型水利/核电/主干电网、区域联通、供能概况与**事件**预告 |
| **公司管理** | 现金流/资产负债、经营记录、社会价值明细、收购、**总监岗位**配置 |
| **年度战略** | 每年 12 月后：年报、贷款、收购上游、下年重点 |

## 核心循环（玩法闭环）

1. 选地区或切大地图（仅已解锁区可深度经营）  
2. 安排建设、研发、贷款、收购  
3. 点击 **下一月**  
4. 自动：工期、电网、供能重算、收支与贷款、**社会价值月度结算**、**公司等级检视**、事件倒计时  
5. 关键节点才弹插画/事件  
6. 回到操作，继续扩张、补强或应对**事件**波动  

## 时间与反馈

- **月**：操作时不流逝；推进后批量结算；**不**做每月固定结果弹窗。  
- **关键节点弹出**：公司等级、重大科技、本地区供能 100%、大型工程竣工、政策/市场类事件等。

## 资源与经济

- **双主资源（长期）**：**资金**、**社会价值**（顶栏常驻）。  
- **资金**：建设（发电/区域链/主干）、用地施工、原材料、运维、研发、还贷、收购等。  
- **建设规则**：指令 → 在建 → **费用按月扣、工期按月走** → 完工次月生效（非即时）。  
- **工期因素**：设施类型、等级、地区地形/规模难度。  
- **地理成本**：大城市偏低 → 中型 → 农村偏高 → 边远最高；**化石能源**为统一标签（利好火电运营成本）。

## 社会价值与进度

- **收束**：无独立经验/社会评价系统，统一为社会价值。  
- **用途**：公司等级、科技、**随等级解锁的可经营区域**、战略工程、贷款条件等。  
- **双组成**：**能源供给社会价值**（约 80%）+ **绿色供能社会价值**（约 20%）；与**当月**供能满足率、清洁占比/火电环保配置挂钩；**按月入账**，与资金结算同节拍。  
- **波动**：拆除或供能率下降可导致**当月社会价值净增量为负**、累计回落；**公司等级只升不降**；**经验条/进度 UI** 须反映相对下一级的进度变化。  
- **公司等级**：与**月度结算**同节拍检视；升级仍属重大节点弹窗。

## 区域解锁节奏（骨架）

- 全图可仍为「两都一十一区」等宏观结构；**可经营区随等级分批开放**（例：1 级 1 区 → 2 级再 +2 区 → 3 级再 +2 区 + 1 超大都市），减轻前期重复与认知负荷。

## 供能与能源

- **单一地区指标**：**供能满足率** = 有效供能 / 当前总需求（无需求梯度）。  
- **有效供能**：额定 + 资源禀赋 + 完工/并网 + 链路损耗 + 储能环保等修正。  
- **首版能源类型**：火电、水电、风电、太阳能、核电；每类突出造价、工期、月运维、有效供能。  
- **风/光**：风能分丰富/一般标签；光伏按日照档位比例 + 储能加成（不做昼夜模拟）。  
- **火电环保**：未配环保则无绿色社会价值；配环保则成本升、可计清洁。

## 地图与建设位

- **结构**：**两都一十一区**（两超大都市 + 十一常规区）；常规区含中心城市 + 农村/边区；区域须差异化（禀赋、成本、联网价值、风光位、化石条件等）。  
- **建设位**：限制风光数量与部分大型设施条件，形成区域策略差异（参考三国志 12 式思路）。

## 电网

- **区域内链路**：连接节点负载均摊；每条链路固定损耗（首版建议 **1MW/条**）。  
- **主干**：跨区域/接大工程；每条固定损耗（首版建议 **1GW/条**）。  
- **不做**复杂距离/电压公式；战略工程在大地图层（大型水利、核电、主干/特高压）。  
- **特高压**：科技解锁后才可高等级跨区组网。

## 科技

- 一次付清研发费、按月推进、**可取消并全额退款**（降低试错）；可并行（满足前置）；重大解锁弹事件。事件亦可调节研发快慢。

## 事件（无竞争公司）

- **大理石时代式**：压力/奖励/市场/政策；主界面入口、倒计时与摘要。  
- **首版作用维度**：**资金投入**、**资金收入**、**研发加快/减慢**；原材料、施工进度等仅作谨慎扩展。  
- **不做**：竞争 AI、区域被夺、夺回与地图变色线。

## 年度经营

- **年报**：建设、线路、费用、收入、研发、净利、**全年社会价值（由 12 次月度结果汇总）** 等。  
- **年度节点专办**：**贷款**（按等级档位）、**收购**上游（1–4 档规模，给成本/周期等固定加成）。  
- **常驻入口**：公司经营、科技树。

## 商业化（分阶段）

- **首发**：仅**广告**，无 IAP。  
- **后续版本**：仅两档**一次性买断**——**6 元财务总监**岗位；**30 元技术总监**岗位 + **去广告**；无抽卡、无其他氪金点。  
- **无成就系统**。

## 胜负与游玩目标（归纳）

- 仍以**长期经营、区域供能与社会价值、科技扩张、应对事件**为主轴；**无**「区域被竞争方夺走」式失败线。  
- 波动与压力主要来自**资金与研发节奏**及供能表现。

## 关键名词速查

下一月、供能满足率、有效供能、社会价值（供给/绿色双条）、**月度社会价值结算**、公司等级（**只升不降**）、经验条、**区域随等级解锁**、区域/主干电网、固定链路损耗、建设位、两都一十一区、化石能源标签、年度贷款/收购、事件节点、财务总监、技术总监、去广告。
