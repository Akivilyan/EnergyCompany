# 游戏核心设计 · 骨架摘要与变更记录

> 本文档为 [`game-core-design.md`](./game-core-design.md) 的**速览骨架**，便于快速把握结构；权威细节以原文为准。

---

## 文档定位与平台

- **范围**：玩法与系统设计，不涉及技术实现。
- **平台**：当前优先微信小游戏；PC 可在同一骨架上增复杂度。
- **名称**：游戏名与公司名不写死，以最新命名为准。

## 设计支柱与原则

- **类型**：轻策略经营；题材为能源建设与区域供能；**静态操作 + 按月推进**。
- **小游戏边界**：保留选区、建设、科技、借贷收购、区域/主干电网、事件压力、资金与社会价值取舍；舍弃手绘逐段线路、逐单位施工、实时时间、复杂物理模拟、多套评分与需求梯度等。
- **目标**：每月有明确决策、阶段目标清晰、建设/节点/事件带来节奏感、复杂度可控。

## 界面结构（四层）

| 层级 | 职责要点 |
|------|-----------|
| **地区主界面** | 最常停留：建设发电与区域电网、在建与工期、供能满足率、运营；顶栏资金/社会价值/年月；`下一月` 主按钮 |
| **全国大地图** | 选区、标签与控制状态、大型水利/核电/主干电网、区域联通、供能与竞争风险 |
| **公司管理** | 现金流/资产负债、经营记录、社会价值明细、收购、负责人配置 |
| **年度战略** | 每年 12 月后：年报、贷款、收购上游、下年建设与研发重点 |

## 核心循环（玩法闭环）

1. 选地区或切大地图  
2. 安排建设、研发、贷款、收购  
3. 点击 **下一月**  
4. 自动：工期、电网、供能重算、收支与贷款、事件倒计时  
5. 关键节点才弹插画/事件  
6. 回到操作，继续扩张、补强或应对竞争  

## 时间与反馈

- **月**：操作时不流逝；推进后批量结算；**不**做每月固定结果弹窗。  
- **关键节点弹出**：公司等级、重大科技、本地区供能 100%、大型工程竣工、关键竞争/政策市场事件等。

## 资源与经济

- **双主资源（长期）**：**资金**、**社会价值**（顶栏常驻）。  
- **资金**：建设（发电/区域链/主干）、用地施工、原材料、运维、研发、还贷、收购等。  
- **建设规则**：指令 → 在建 → **费用按月扣、工期按月走** → 完工次月生效（非即时）。  
- **工期因素**：设施类型、等级、地区地形/规模难度。  
- **地理成本**：大城市偏低 → 中型 → 农村偏高 → 边远最高；**化石能源**为统一标签（利好火电运营成本）。

## 社会价值与进度

- **收束**：无独立经验/社会评价系统，统一为社会价值。  
- **用途**：公司等级、科技/区域/战略工程/贷款条件等解锁。  
- **双组成**（年报展示）：**能源供给社会价值**（约 80% 基准权重）+ **绿色供能社会价值**（约 20%）；与供能满足率、清洁占比/火电环保配置挂钩；**年度 12 月一次性入账**，非按月即时。  
- **公司等级**：由累计社会价值驱动；升级属重大节点弹窗。

## 供能与能源

- **单一地区指标**：**供能满足率** = 有效供能 / 当前总需求（无需求梯度）。  
- **有效供能**：额定 + 资源禀赋 + 完工/并网 + 链路损耗 + 储能环保等修正。  
- **首版能源类型**：火电、水电、风电、太阳能、核电；每类突出造价、工期、月运维、有效供能。  
- **风/光**：风能分丰富/一般标签；光伏按日照档位比例 + 储能加成（不做昼夜模拟）。  
- **火电环保**：未配环保则无绿色社会价值；配环保则成本升、可计清洁。

## 地图与建设位

- **结构**：**两都一十一区**（两超大都市 + 十一常规区）；常规区含中心城市 + 农村/边区；区域须差异化（禀赋、成本、联网价值、风光位、化石条件等）。  
- **建设位**：限制风光数量与部分大型设施条件，形成区域策略差异（参考三国志 12 式思路）。

## 电网

- **区域内链路**：连接节点负载均摊；每条链路固定损耗（首版建议 **1MW/条**）。  
- **主干**：跨区域/接大工程；每条固定损耗（首版建议 **1GW/条**）。  
- **不做**复杂距离/电压公式；战略工程在大地图层（大型水利、核电、主干/特高压）。  
- **特高压**：科技解锁后才可高等级跨区组网。

## 科技

- 一次付清研发费、按月推进、**可取消并全额退款**（降低试错）；可并行（满足前置）；重大解锁弹事件。

## 事件与竞争

- **事件**（大理石时代式）：压力/奖励/市场/政策；主界面入口查看倒计时与波动因素。  
- **竞争公司**：非全图 AI；**倒计时事件** → 明确区域压力 → 影响地图控制；失守则失经营权与后续该区域社会价值。  
- **夺回**：科技覆盖/超越对方 + 支付收购价（建议为区域设施投入的 **2–3 倍**）。

## 年度经营

- **年报**：建设、线路、费用、收入、研发、净利、各地区新增社会价值等。  
- **年度节点专办**：**贷款**（按等级档位）、**收购**上游（1–4 档规模，给成本/周期等固定加成）。  
- **常驻入口**：公司经营、科技树。

## 成就与商业化

- **成就**：中长期目标与记忆点，**不宜**强数值绑架（例：核电科技、低资金全年、全图覆盖等）。  
- **战略支撑负责人**（核心商业化）：建设/科研/财务三类，影响周期与费用、贷款收购与原材料成本等；槽位可礼包扩展；首充/礼包示例见原文。

## 胜负与游玩目标（原文归纳）

- 原文**未单独定义**传统「通关/胜利」条件；骨架以**长期经营、区域供能与社会价值、科技地图扩张、应对竞争事件**为主轴。  
- **失利代价**主要体现在**区域被竞争方夺走**及夺回门槛；非动作「战斗」系统。

## 关键名词速查

下一月、供能满足率、有效供能、社会价值（供给/绿色双条）、公司等级、区域/主干电网、固定链路损耗、建设位、两都一十一区、化石能源标签、年度结算、贷款、收购、事件节点、竞争倒计时、战略支撑负责人、成就。
