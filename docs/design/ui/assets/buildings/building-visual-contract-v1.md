## 2. 统一观察与透视合同

### 2.1 正式方案 A′：高机位弱透视三分之四俯视

- **观察方位**：固定看见建筑正面与右侧面，右侧面约占可见立面 35%—45%；同一设施不得左右翻转充当另一版本。
- **镜头高度**：视线向下约 38°，允许 ±3° 制作误差；优先展示屋顶、管线与占地关系，同时保留足够正立面。
- **水平偏角**：相对正面向右偏约 35°；长边设施仍按场景道路 / 建设位方向摆放，不为填满画布旋转。
- **透视类型**：2.5D 轻微弱透视。竖线保持平行；一个标准占地深度内的近远尺度差不超过约 5%；保留 A 高机位的细节优势，但不使用完全无纵深的严格正交图标视角。
- **画面读法**：建筑首先是场景内设施，其次才是可裁切素材。地表道路、邻近地块和镜头关系优先于单体“英雄角度”。

### 2.2 首轮对比稿候选（历史）

| 编号 | 角度 / 透视 | 用途判断 |
|------|-------------|----------|
| A | 约 38° 高机位，严格正交 / 等距 | 屋顶信息清楚，但立面和视觉高度被压缩，容易变成微缩策略图标 |
| B | 约 30° 中机位，弱透视三分之四俯视 | 首轮曾推荐，复评后未采用；屋顶与管线细节不如 A 高机位充分 |
| C | 约 20° 低机位，明显透视 | 体量强但遮挡严重，易成为孤立宣传模型，难以复用到密集城市布局 |

A′ 以 A 的高机位为基础，并加入轻微弱透视作为正式镜头族；B、C 与严格正交 A 只保留在对比稿中，不作为变体资产。

## 3. 光照合同

- **时间**：晴朗正午；不做晨昏、夜景、灾害天气或设施专属光照版本。
- **主光方向**：接近画面顶部、略偏镜头前方垂直照下；屋顶与主要立面均匀可读，投影只略向物体后方偏移。
- **主光性质**：暖白、清晰但不硬；高光只帮助读材质与轮廓，不制造过曝白边。
- **天空补光**：来自上方与背光侧的清透天蓝环境光，背光面亮度不低于受光面的约 65%；主体色必须在背光面仍可辨。
- **地面反射**：浅灰绿 / 湖蓝环境反射只作用于下部结构，不能把整个设施染蓝。
- **环境遮蔽**：只出现在支脚、墙根、管线交界和结构缝隙；不得形成连续黑块。
- **接地阴影**：很短、软、低透明的浅蓝灰影，普通主体投影长度约为设施可见高度的 8%—15%；H4 风机仍以不超过约 20% 为目标。接触点另保留一圈窄 AO，禁止厚黑椭圆底座。
- **状态光效**：不烘焙进建筑母图。可建、选中、在建、完成和锁定由独立轮廓、遮罩、施工与光效层表达。

首轮 D / E / F 使用 B 的几何关系，只作为历史对比。正式光照沿用第二轮 L3：接近顶部的正午主光、充足天空补光和最短软影。

## 4. 占地、视觉高度与比例

### 4.1 占地轮廓

- 占地轮廓描述建筑真实接触地面的范围，不包含投影、叶片、烟囱外飘管线或交互光环。
- 母图必须能叠加一条简洁的地表占地轮廓做 QA，但最终建筑层不自带厚平台、圆形徽章底或完整独立小岛。
- 建筑可带必要的薄地基、维护步道和设备脚座；地基高度不得超过主体视觉高度的 6%。

| 占地级别 | 逻辑包围盒 | 适用示例 | 目标场景宽度 |
|----------|------------|----------|--------------|
| S | 1.0 × 1.0 标准位 | 单台风机、电网小节点（若未来玩法确认） | 标准地块宽的 55%—70% |
| M | 1.5 × 1.0 标准位 | 火电主体、光伏追日器的实体基座 | 标准地块宽的 80%—105% |
| L | 2.0 × 1.5 标准位 | 光伏追日器的完整旋转安全包围、核电、水电复合体 | 仅在专用大地块中使用，不缩成 M 级硬塞 |

实际玩法当前只有“占用一个建设位”的规则，上表是视觉包围盒而非新增槽位消耗规则；不得据此改动建设数值。

### 4.2 视觉高度

| 高度级别 | 相对标准地块宽 | 适用示例 |
|----------|----------------|----------|
| H1 贴地 | 0.20—0.35 | 地面设备、维护构件 |
| H2 低 | 0.35—0.65 | 光伏追日器基座、低层机房、辅助设施 |
| H3 中 | 0.65—1.05 | 光伏追日器受光面、火电主厂房、常规工业体 |
| H4 高 | 1.05—1.65 | 风机、烟囱、核电冷却塔等识别构件 |

同一设施可包含多个高度构件，但必须声明主高度级别和最高越界级别。不得为缩略图单独压扁 H4 构件。

## 5. 场景锚点与接地规则

- **主锚点**：建筑占地轮廓的屏幕下缘中心，即最靠近镜头的地面接触点；不是 PNG 外框中心，也不是阴影中心。
- **规范坐标**：以裁切后资产为 0—1，主锚点建议 `x = 0.50`；`y = 0.84—0.90`，具体值随顶部越界高度记录在资产清单。
- **深度排序**：使用主锚点的场景 Y 值排序；高塔和叶片不改变地面排序点。
- **接地完整性**：最终母图必须保留全部接触点、薄地基和完整接地阴影；不得在脚部裁切，也不得用模糊光晕掩盖悬浮。
- **场景比例检查**：所有代表设施必须同时放在同一标准建设位、道路宽度和树木标尺下检查；禁止分别缩放到“每栋都刚好填满画布”。

## 6. 母图尺寸与缩略图裁切

- 建筑资产按实际占屏生产，母图长边约 256—512px：普通 M 级优先 384—512px，H4 / L 级可用 512px 长边；不使用图标阶段的统一 128px，也不生成 2K 单栋建筑。
- 城市测试场景允许约 2048px 长边或分层 / 分块；场景只用于比例与组合验证，不合并回单栋建筑。
- 功能图标继续维持既有 64 / 128px 合同；九宫格玻璃面板只做可拉伸边角，不制作整屏大图。
- **母图裁切**：保留几何包围盒四周约 6%—10% 安全留白，H4 顶部可到 12%；接地阴影必须完整。
- **设施缩略图**：只从同一母图裁切 / 重排，使用相同角度和光照。以主体轮廓占缩略框 72%—82% 为目标；保留地面接触和一小段阴影，不附加厚底座、圆角 App 容器或不同背景插画。
- 缩略图中若长构件难以识别，优先调整裁切与局部对比，不重画正视版，不加无玩法依据的标志物。

## 7. 同场景验收门槛

1. 在同一约 2048px 测试场景放置风电·I、光伏·I、火电·I，统一道路、地块、树木和镜头。
2. 不看文字时，三者能从轮廓与主色区分；缩至城市实际占屏后仍可识别。
3. 三者占地、脚点和投影方向一致，无悬浮、无厚重底座、无各自独立“展台”。
4. H2 / H3 光伏追日器不因立起而接近 H4 风机总高；火电不因结构复杂而压过城市主场景。
5. 背光面仍能区分钴蓝、珊瑚橙和天空蓝白；深色机械结构不形成连续暗块。
6. 从母图裁出的设施缩略图与场景内同一设施保持同角度、同光照、同主色身份。

当前测试结果：第 1—5 项在 1774×887 场景级 v4 稿中通过；第 6 项需要在后续 256—512px 代表建筑母图与缩略图裁切阶段执行，不能用本场景截图冒充母图。

## 8. 已确认决策

- **镜头 A′**：约 38° 高机位、正面与右侧面可见、竖线平行，并保留轻微弱透视。
- **光照 L3**：接近顶部、略偏镜头前方的正午主光，投影最短，屋顶与立面最均匀。
- 所有后续城市建筑沿用 A′ + L3；不再为同一建筑生产 A / B / C 或 L1 / L2 变体。
- 当前只评审风电·I、光伏·I、火电·I 的同场景比例与色彩；不制作完整城市组合，不扩展区域或世界地图。

## 9. 对比稿生成与 QA 记录

- 生成方式：内置图像生成；两张既有城市图仅作为视觉方向参考，对比稿为新生成图，不修改既有方案。
- 归一化提示词：`明亮新能源城市的建筑视觉合同对比表；同一座真实类型的火电·I 在 2×3 网格中保持设施几何、配色和占地一致；A/B/C 只比较高位正交、中位弱透视、低位强透视；D/E/F 固定 B 镜头，只比较过平光、推荐正午光、过强戏剧光；珊瑚橙与杏橙主体、浅蓝灰结构、双烟囱、少量洁净管线；薄地基、真实接地、短软阴影；无 HUD、无其它建筑、无完整城市、无厚底座、无污染烟雾、无水印。`

- 已知边界：生成图只能用于方向评审，不可据此提取六套设施；合同确认后的建筑母图仍需按 256—512px 分级、统一锚点和同场景比例重新生产。

## 11. 代表设施同场景记录

- 当前文件：[`building-representative-scale-grounding-test-v4.png`](../../concepts/building-representative-scale-grounding-test-v4.png)，1774×887 PNG。v1—v3 保留为光伏修订历史，不覆盖、不删除。
- 生成方式：内置图像生成；v4 以 v3 场景为编辑目标，并使用用户提供的低分辨率参考图提取“矩形面板 + 中央转轴 + 低矮交叉支撑”的机械读法；没有复制参考模型，风电、火电、场景、镜头和比例保持不变。
- 归一化提示词：`只修改同场景中央光伏·I；使用一整块立式矩形 3×4 钴蓝光伏面，带白青框架与轻微倒角；面板通过双叉俯仰支架连接暖黄转轴，支架落在青色水平旋转环和短立柱上；底部使用贴地四臂 X 形基础、圆角脚点、细青色能量线和小型逆变器；结构必须一眼说明“整块面板可以俯仰，整机可以水平旋转”，像向日葵追日但不画植物花瓣；保持 A′ 镜头、L3 光照、风电、火电、道路、树木不变。`
- 比例检查：风机为 H4 最高且占地最窄；光伏受光面为 H3、基座为 H2，整体低于风机轮毂和火电烟囱；火电主质量为 H3、烟囱越界到 H4，三者未被分别缩放到填满画布。
- 接地检查：三者地面接触点完整，维护铺地与草地齐平，没有厚底座、孤立展台或悬浮；投影已按 L3 收短。
- 辨识检查：缩至场景总览仍能从白蓝黄风机、矩形钴蓝追日光伏、珊瑚橙火电的轮廓与主色区分，不依赖文字标签；光伏 v4 的未来感来自可读转轴、旋转环与支撑结构，不依赖悬浮或无玩法依据的大型发光核心。
- 资产边界：本图只用于同场景合同验收，不进入小游戏包，也不能直接裁成三栋母图；下一步只在本组三种设施通过后制作 256—512px 分级母图与缩略图裁切示例。
