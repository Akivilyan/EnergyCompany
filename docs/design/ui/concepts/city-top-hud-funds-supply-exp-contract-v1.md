# 城市顶部 HUD / 公司 EXP 方案 v1

> 状态：高保真提案；对应 `city-top-hud-funds-supply-exp-v2.png`。只定义玩家可见信息与反馈语义，不实现 Cocos。

## 1. 城市顶部 HUD

### 常驻信息

| 位置 | 信息 | 数据语义 |
|------|------|----------|
| 左上资金胶囊 | 金币图标 + 当前资金 | `funds` 当前值 |
| 右上时间胶囊 | 日历 A + `第 N 月` | `currentMonth`；时间状态，不属于资源 |
| 第二行供能条 | 有效供能 / 需求、满足率、缺口 | `effectiveSupplyMw / demandMw`、`supplyRatio`、`supplyGapMw` |

城市 HUD 不常驻 SV / EXP、科技点、贷款、详细现金流或“每回合资金增长预测”。科技点只在科技页资源区与节点中出现；经营明细在公司页查看。

### 供能条

- 紧贴顶部资金 / 时间行，保持同一毛玻璃组件组。
- 左侧使用已认可的青蓝闪电；主数字显示 `有效供能 / 需求 MW`，右侧显示满足率。
- 填充长度表达 `supplyRatio`，上限为 100%；缺口显示 `max(0, demandMw - effectiveSupplyMw)`。
- 有缺口时使用红色短文本 `缺口 N MW`；缺口为 0 时改为 `供能充足`。
- 颜色不是唯一信息：始终同时保留数字、百分比和缺口 / 充足短文本。

## 2. 瞬时变化反馈

### 资金

- 建设、贷款、广告奖励、灾害扣款或月结导致资金变化后，在资金胶囊下缘附着一个短时 delta。
- 正向使用 `+N` 与绿色，负向使用 `-N` 与珊瑚红；符号和数字承担非颜色冗余。
- `+N / -N` 只表示本次动作或刚完成结算的变化，不表示周期资金增加值，也不作为资源栏第二行常驻数据。
- 建议停留约 2 秒，随后 250ms 淡出；连续同源变化可合并，详细来源保留在公司页现金流。

### 供能

- 月结后供能发生变化时，可在供能条对应位置短暂附着 `+N MW / -N MW`。
- 条的常驻值立即更新到最新有效供能、满足率和缺口；delta 只负责解释刚发生的变化。

## 3. 公司 EXP

- `socialValueCurrent` 从城市 HUD 移到公司页，玩家层命名为公司经验 `EXP`。
- 公司页显示：等级图标、`公司等级 N`、`current / nextThreshold EXP`、距升级差值。
- EXP 使用粉紫实体字形 `EXP`，不再制作 SV 星形资源图标。
- 进度条按 `socialValueCurrent / 下一等级绝对门槛` 显示；到达最高等级后显示满条与 `最高等级`。
- 当前公司经验会随供能与环保结果波动，但 `companyLevel` 只升不降；组件必须明确提示“经验会波动，已获得等级不会回退”。

## 4. 三个演示状态

| 状态 | 资金 | 月份 | 供能 |
|------|------|------|------|
| 默认 | `229`，无 delta | 第 3 月 | `870 / 1320 MW`、66%、缺口 450 MW |
| 建设后 | `217`、短时 `-12` | 第 3 月 | 不变 |
| 月结后 | `255`、短时 `+38` | 第 4 月 | `912 / 1320 MW`、69%、缺口 408 MW、短时 `+42 MW` |

演示数字只用于说明组件状态；运行时显示真实快照与本次结果。
