## 暂不制作

| 类别 | 暂缓原因 |
|------|----------|
| 地图、区域、世界入口 | 后续场景层级与导航入口尚未完成正式页面验证，不能从当前占位图标反推 |
| 公司、科技页面入口 | 入口数量、位置与常驻方式尚未锁定；科技节点图标不等于科技页入口 |
| 贷款、广告 | 属于低频业务，不进入当前高频图标批次 |
| 具体灾害类型全集 | 当前只需通用警告与已验证事件表达，不预制未进入代表流程的类型 |
| 政策、市场、里程碑类型全集 | 具体可见分类与交互尚未锁定 |
| 建筑 / 设施类别图标 | 建筑视觉合同与代表建筑属于下一资产阶段，不以功能图标提前替代 |
| 城市、区域、世界节点符号 | 属于后续独立场景阶段 |
| 设置、帮助、教程及其它低频工具图标 | 不是当前首局垂直流程的高频缺口 |

## 本批确认方案

最终资产清单见 `../assets/icons/icon-manifest-v2.md`。v1—v2 的空心电路环、节点网方向已否决：它们更像 DNA / 生物科技品牌标识，不符合快速月报中闪电与金币的饱满实体资源符号语言。

### 等级 I—V

- 锁定实体罗马数字 I—V，不附加光点、能量条或下划线。
- 颜色依次锁定为蓝、绿、黄、橙、红。
- 数字形状与颜色共同表达等级，不依赖颜色单独编码。

### 科技节点

- 锁定 B 组实体芯片。
- 正常、选中、锁定三态共享同一芯片主体，仅改变描边 / 光晕、亮度和锁定遮罩。
- 科技树节点与研发完成反馈共用同一图标母版；当前规则不显示科技点资源数量。

### 高频动作与状态

- 锁定组合为 `BAAAA`：建设 B（锤子）、升级 A（上箭头）、锁定 A（挂锁）、完成 A（终点旗）、通用警告 A（三角叹号）。
- 母版见 `functional-icon-action-state-exploration-v2.png`；v1 与 v2 中未选方案继续保留，未来只有在吊装、施工安全、阶梯成长、强制阻断、成就章或紧急警报等语义被正式定义时才允许复用。
- 未选方案不进入当前正式资产清单，也不得与已锁定主语义混用。

### 清洁供能状态

- 锁定 A / B 组合：完全清洁使用绿色叶片 + 对勾；待改善使用黄色叶片 + 感叹号。颜色与符号共同编码状态。
- 黄色待改善态保持积极、醒目的改进提示，不使用灰色叶片制造“不可用 / 已失败”的否定感。
- 锁定稿见 `functional-icon-clean-supply-state-exploration-v2.png`；v1 中灰叶、斜杠、内嵌叉号等未选方案继续保留，但不进入当前正式资产。
- 该状态只说明当前供能是否完全清洁，不表示清洁能源占比。

## 已完成交付

- 已交付 24 枚 128×128 独立透明 PNG、统一命名与用途清单，以及 32 / 48 / 64px 缩小预览。
