# 正式功能图标生产清单 v1

> 范围：`PRODUCT-PROTOTYPE-01` 正式图标资产。本文只整理已经由当前 UI 设计合同明确的高频语义，不扩展玩法；建筑、城市、区域、世界地图资产不在本清单内。

## 已有并锁定

| 图标 | 锁定方案 | 用途边界 |
|------|----------|----------|
| 日历 | A | 月份、持续月数、时间信息；不代替倒计时或进度 |
| 即时 | A | 一次性即时影响；不表示持续状态 |
| 详情 | A | 查看详情或展开信息 |
| 回合收入 | B | 月度 / 回合收入变化 |
| 持续减少 | A | 持续负向影响或倍率下降 |
| 确认 | A | 玩家确认动作；不直接兼作“项目已完成”状态 |

锁定图标只沿用，不重新设计。母版分别为 `functional-icon-simplified-exploration-v1.png` 与 `functional-icon-system-exploration-v2.png`。

## 暂不制作

| 类别 | 暂缓原因 |
|------|----------|
| 地图、区域、世界入口 | 后续场景层级与导航入口尚未完成正式页面验证，不能从当前占位图标反推 |
| 公司、科技页面入口 | 入口数量、位置与常驻方式尚未锁定；科技点资源图标不等于科技页入口 |
| 贷款、广告 | 属于低频业务，不进入当前高频图标批次 |
| 具体灾害类型全集 | 当前只需通用警告与已验证事件表达，不预制未进入代表流程的类型 |
| 政策、市场、里程碑类型全集 | 具体可见分类与交互尚未锁定 |
| 建筑 / 设施类别图标 | 建筑视觉合同与代表建筑属于下一资产阶段，不以功能图标提前替代 |
| 城市、区域、世界节点符号 | 属于后续独立场景阶段 |
| 设置、帮助、教程及其它低频工具图标 | 不是当前首局垂直流程的高频缺口 |

## 本批确认方案

最终资产清单见 `../assets/icons/icon-manifest-v1.md`。v1—v2 的空心电路环、节点网方向已否决：它们更像 DNA / 生物科技品牌标识，不符合快速月报中闪电与金币的饱满实体资源符号语言。

### 等级 I—V

- 锁定实体罗马数字 I—V，不附加光点、能量条或下划线。
- 颜色依次锁定为蓝、绿、黄、橙、红。
- 数字形状与颜色共同表达等级，不依赖颜色单独编码。

### 科技点

- 锁定 B 组实体芯片。
- 正常、选中、锁定三态共享同一芯片主体，仅改变描边 / 光晕、亮度和锁定遮罩。
- 科技页资源区、科技树节点与月报共用同一图标母版。

## 选择后交付边界

方案确认后才制作独立透明 PNG、统一命名与用途清单、真实 32 / 48 / 64px 缩小预览，以及必要的正常、选中、锁定状态。所有状态共享同一图形母版，不因状态重新绘制主体。
