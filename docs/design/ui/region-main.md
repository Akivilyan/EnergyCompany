# 地区主界面

> 状态：待重设计；本文只保留页面目的、玩法输入与行为边界，不作为布局、组件或视觉基准。

## 1. 屏幕与目的

- 屏幕 ID：`screen_region`。
- 在单一区域内查看城市节点、已有 / 在建链路，选择城市进入经营，或发起区内铺线。
- 本屏不提供 `下一月`；时间只在城市页推进。

## 2. 玩家可见对象

- 城市节点：可操作、只读、锁定等状态。
- 区内电网链路：未建、可建、施工中、已联通状态。
- 返回世界地图、进入城市，以及科技 / 公司等全局页面的上下文入口；具体位置待重设计。

## 3. 行为合同

| 对象 / 动作 | 条件 | 结果 |
|-------------|------|------|
| 点击可操作城市 | 城市可用 | 进入 `screen_city_detail` |
| 点击只读 / 锁定城市 | 城市不可操作 | 显示摘要或解锁条件 |
| 选择两个城市节点 | 链路允许建设 | 进入区内建线确认 |
| 确认建线 | 科技、资金与端点合法 | `queue_grid_link` |
| 返回世界地图 | 任意可操作态 | 进入 `screen_world_map` |
| 进入科技 / 公司 | 对应入口已开放 | 进入全局管理页面 |

## 4. 状态与交互底线

- 仅一个城市可操作时不突出建线操作。
- 资金不足时保留链路信息与缺口说明，但禁用确认。
- `month_settling` 时禁用地图输入并沿用统一结算反馈。
- 教学阶段只开放引导白名单内的节点与入口。
- 城市节点必须有可靠触控热区；地图拖拽与点选手势分离。
- 区域场景强调城市节点、路径和地理分区，不承载城市级建筑细节。
