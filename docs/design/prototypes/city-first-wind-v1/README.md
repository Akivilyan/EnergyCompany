# 城市场景垂直切片 v1

> 设计阶段浏览器原型；不依赖 Cocos，不代表正式客户端实现。

## 范围

- 真实点击闭环：空位 → 候选 → 确认 → 开工 → 推月 → 完工。
- 使用 `representative-v1` 中的风电·I、光伏·I、火电·I 正式母图与同源缩略图。
- 390×844 主尺寸与 430×932 响应式复核。
- 城市场景只使用足以验证建设位、遮挡、HUD 和 sheet 的设计底板，不是完整城市资产。

## 本地启动

在仓库根目录运行：

```powershell
npm.cmd run prototype:city
```

浏览器打开命令输出的本地地址。该命令只启动本地静态服务，不打开或修改 Cocos 工程。

## 快速检查

```powershell
npm.cmd run prototype:city:check
```

此检查覆盖文件、正式资产路径、浏览器自动化钩子及默认风电完整状态流；真实浏览器点击与双尺寸截图另行执行。

## 不做

- 不接入 Cocos、微信开发者工具或现有临时客户端。
- 不新增建筑、图标、区域、世界地图或灾害场景资产。
- 不作为规则真理源；数值仅来自当前设计合同中的竖切锚点。
