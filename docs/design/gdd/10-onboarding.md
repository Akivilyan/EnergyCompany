# 新手引导与教程

## 概述

本章定义 **首版必须** 的新手引导。

**核心结构**：在 [新游戏](./11-replayability.md) 的 **方针选择屏** 上，除风光 / 水电 / 化石 / 科技四方针外，增加 **「教学」方针**（`doctrine_tutorial`）。该选项 = **教学关卡**：走 **8 步强制遮罩**；可 **跳过**、可 **重玩**；**通关教学** 后在选项上显示 **已完成标记（打勾）**。

**正式对局**（四方针任选）：**不跑** 强制遮罩，靠 **教程图鉴** + **弱提示** 自学。

**不做**：把教学链绑死在某一正式方针上；不做与正式存档混用的「半教程半真局」。

---

## 设计评价（为何用「教学方针」）

| 对比 | 仅 `tech` 走遮罩 | **独立「教学」方针**（本方案） |
|------|------------------|-------------------------------|
| 玩家心智 | 「科技 = 新手局？」易误解 | **教学 = 教程**；四方针都是正式玩法 |
| 重玩 | 为看教程得开科技局 | 方针屏 **随时再点教学** |
| 完成感 | 无集中标记 | **打勾** = 已学过教程 |
| 与局外成长 | 和科技 meta 混在一起 | 教学 **可不占** 方针局外等级（见下） |

## 教学方针（教学关卡）

### 定位

| 项 | 说明 |
|----|------|
| 目的 | 在 **低风险、短流程** 内教会核心循环 + II 级科技树入口 |
| 局内规则 | **固定教学配置**（`tutorial_run_config`）：建议 **简单难度**、固定起始资金、**缩短** 至升级 II 的社会价值门槛（具体 T37）；**不** 套用四方针 modifier |
| 地图 | 同 `CITY-START` 单城起手；II 级后开放科技树 **单队列** 演示（与 [07-tech.md](./07-tech.md) 一致） |
| 结局 | 走完 `onb_07` 或玩家跳过 → **结束本局教学** → 回到 **方针选择屏** 或主菜单（不强制立刻开正式局） |
| 灾害战役 | 教学局 **不触发** 战役通关轴 / 或仅到第一场前结束（T37 裁剪，避免教程过长） |

### 完成标记（打勾）

| 字段 | 存储 | 说明 |
|------|------|------|
| `tutorial_doctrine_cleared` | **玩家档案**（跨局） | `true` = 曾 **完整走完** 8 步强制链（`onb_done`） |

| UI | 规则 |
|----|------|
| 方针屏「教学」卡片 | `tutorial_doctrine_cleared` → 角标 **✓ / 已完成** |
| 跳过教学 | **不** 置 `tutorial_doctrine_cleared`；**无打勾** |
| 重玩教学 | 可再次选择 `tutorial`；打勾 **保持**（不因重玩消失） |

### 跳过

与强制链内 **跳过引导** 相同：二次确认 → 本局教学结束 → 回方针屏；**无打勾**。

### 重玩

| 入口 | 行为 |
|------|------|
| 方针屏再选 **教学** | 新开 **教学局**（重置教学专用进度）；再走 8 步（或从断点续，见存档） |
| 教程图鉴 | 静态查阅，随时可看 |
| 遮罩重播 | 可选实现：图鉴内「重走教学」= 跳转方针屏并选中教学 |

**首访**：未 `tutorial_doctrine_cleared` 时，可对 **教学** 卡片 **推荐高亮**（「新玩家由此开始」）。

## 设计原则（强制链）

| 原则 | 说明 |
|------|------|
| **遮罩独占** | 仅高亮目标可点；**禁止** 未放行切屏（公司/地图/科技等） |
| **可跳过** | 每步可跳过全部教学 |
| **不抢大事件** | 升级、灾害全屏优先；引导暂停后续播 |
| **8 步** | 含方针屏内对「教学」的确认（若算入则步骤条在进城后 1～7） |

---

## 遮罩交互

| 规则 | 说明 |
|------|------|
| **点击** | **仅** `highlight_target` 可点 |
| **导航** | 未放行不可进公司/科技/地图/区域/事件 |
| **指引** | 高亮 + 手指 + 步骤条（教学局内 **1/7～7/7** 或 **1/8～8/8** 若含确认步） |

## 强制引导链（仅 `doctrine_id = tutorial`）

**触发**：方针屏选定 **教学** 并确认 → 进入 `CITY-START` → 自动从 `onb_01` 开始（**无** 单独 `onb_00` 遮罩文案绑在四方针上）。

| 步 | `step_id` | 界面 | 教学目标 | 完成条件（摘要） |
|----|-----------|------|----------|------------------|
| 1 | `onb_01_welcome` | `screen_city_detail` | 单城、供能与社会价值 | 确认 |
| 2 | `onb_02_build` | 城市 + 建造 | 点空位 → 选 ·I 设施；首月扣款 | 已下达建设 |
| 3 | `onb_03_next_month` | 城市 | **下一月** | 推月 1 次 |
| 4 | `onb_04_read_dashboard` | 城市 | 顶栏、供能条、在建 | 确认 |
| 5 | `onb_05_push_to_finish` | 城市 | 推月至完工或满足率 ≥ 60% | `built` 或 sat ≥ 0.6 |
| 6 | `onb_06_company` | `screen_company` | **本步解锁** 公司入口；经营快照 | 进入并关闭引导 |
| 7 | `onb_07_tech_ii` | II 升级后 → 科技树 | 单队列研发演示 | 打开科技树并确认 |
| — | `onb_done` | — | 教学关结束 | `tutorial_doctrine_cleared=true`；回方针屏 |

**结束后**：弹出短句「教程完成，请选择方针开始正式游戏」→ **方针选择屏**（教学卡显示 ✓）。

## 存档字段

### 玩家档案（跨局）

| 字段 | 说明 |
|------|------|
| `tutorial_doctrine_cleared` | 教学关 **完整完成** → 方针屏打勾 |

### 教学局（单局）

| 字段 | 说明 |
|------|------|
| `is_tutorial_run` | `doctrine_id == tutorial` |
| `onboarding_current_step_id` | 教学断点 |
| `onboarding_skipped` | 本局是否跳过 |
| `onboarding_steps_done` | 已完成步骤 |

### 正式局（单局）

| 字段 | 说明 |
|------|------|
| `onboarding_tips_seen` | 弱提示 |

**继续游戏**：仅当 `is_tutorial_run` 且未完成时续播教学断点；正式局不续播强制链。

## 新游戏总流程

```text
主菜单 → 新游戏 → 选难度
  → 方针屏（教学✓? + 风光水电科技）
      ├─ 选「教学」→ 教学局 → 8 步遮罩 → onb_done → 回方针屏（教学打勾）
      └─ 选四方针之一 → 正式局（无遮罩，弱提示）
```

## 已决事项

| 议题 | 决策 |
|------|------|
| 教学入口 | 方针屏 **独立「教学」** 选项 |
| 四方针 | **无** 强制遮罩 |
| 打勾 | 仅 **完整完成** 教学关；跳过不打勾 |
| 重玩 | 可反复选教学；打勾保留 |
| 遮罩 | **仅** 教学局；**不可** 旁路切屏 |
| 教学局局外 | **不计** 方针 meta 等级 |
| 教学局结束 | 回 **方针选择屏**（或主菜单）；可再开正式局 |
| 强制链 | **7+done** 步；遮罩 **8** 步展示可含确认 |
