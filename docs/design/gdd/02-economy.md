# 资源与经济

## 概述

本章定义小游戏版的**经济资源体系**与**资金侧规则**：双主资源中的**资金**如何获得与消耗、**建设**如何扣费与推进工期、**地区标签**如何影响成本。

**社会价值**的规则（公式、等级、解锁）见 [社会价值与公司等级](./03-social-value.md)；本章仅说明其在顶栏与资金形成**长期取舍**。

**首版不做**上游企业收购；资金用途与战略界面均**不包含收购**（见 [已决事项](#已决事项)）。

---

## 双主资源（经济视角）

| 资源 | 经济侧角色 | 详细规则 |
|------|------------|----------|
| **资金** | 建设与运营的硬约束；可负债（贷款） | 本章 |
| **社会价值** | 非直接购买，但解锁区域/科技/贷款档位 | [03-social-value.md](./03-social-value.md) |

两资源在 **城市详细建设界面** 顶栏常驻（见 [核心循环与时间](./01-core-loop.md)）。

---

## 资金用途

首版中，资金可用于：

| 用途 | 说明 | 发生界面/时机 |
|------|------|----------------|
| 建设发电设施 | 城市建造位上建站 | 城市界面；费用按月扣 |
| 建设区域电网链路 | 区域内城市间线路 | 区域界面；费用按月扣 |
| 建设主干电网 | 区域间连接核心城市 | 大地图；费用按月扣 |
| 用地与施工 | 并入建设总造价或单列（数值表定） | 建设下达时 |
| 原材料成本 | 运营侧，按月结算 | 月度管道 M7 |
| 运维成本 | 设施运行，按月结算 | 月度管道 M6 |
| 研发费用 | 科技一次付清或按月（见 [科技研发](./07-tech.md)） | 科技树 |
| 贷款本息 | 有且仅有 1 笔活跃贷款时的还款 | 月度管道 M8；申请见 [01-core-loop](./01-core-loop.md) |

**首版不包含**：收购上游企业、任何与收购相关的资金支出。

---

## 设施建设规则

建设**不是即时完成**。

### 流程

```text
玩家下达建设指令
    → 项目进入「在建」
    → 建设费用按月从资金扣除
    → 工期按月推进
    → 完工后，供能/链路效果从次月开始生效
```

### 费用分摊示例

| 项目 | 总造价 | 工期 | 每月扣款 |
|------|--------|------|----------|
| 中型火电站（示例） | 30M | 3 个月 | 每月 10M |

具体造价与工期由设施类型、等级、地区难度决定（见下）；数值见 `data/` 配置表。

### 取消与拆除

- **在建项目**：是否可取消、是否退款，在 [建设 Feature](../features/construction.md)（T15）与数值表共同定义；GDD 默认倾向：取消可停扣款，已付费用是否部分返还待表。
- **已完工设施**：若允许拆除，资金与社会价值影响见 [社会价值](./03-social-value.md)（供能回落可能导致社会价值扣减）。

---

## 建设工期

首版工期**只**由以下三因素决定：

| 因素 | 说明 |
|------|------|
| `facility_type` | 火电、水电、风电、太阳能、核电等 |
| `facility_tier` | 设施等级/规模档 |
| `region_difficulty` | 地区地形或规模难度（与地图章一致） |

不在首版引入：施工单位数量、天气随机延误（特殊事件可临时影响，见 [事件系统](./08-events.md)）。

---

## 建设与运维的地理差异

地区**标签**与**城市类型**影响造价与运营成本（倍率进数值表，本章只定原则）。

| 地区/城市类型 | 建设成本 | 运营成本 |
|---------------|----------|----------|
| 大城市 | 偏低 | 偏低 |
| 中型城市 | 中等 | 中等 |
| 农村 | 偏高 | 中等偏高 |
| 边远地区 | 最高 | 最高 |

玩家在建设选点时应能看到**预估造价/工期/运维**（UI 在 T30 定义）。

---

## 地区标签：化石能源 `fossil_energy`

首版**不**再细分煤炭、石油、天然气三类标签。

| 标签 ID | 含义 | 玩法效果 |
|---------|------|----------|
| `fossil_energy` | 该地区化石能源供应条件好 | **火电类**设施在本地区的**运营成本下降** |

- 以**图标**在地图/建设界面展示。
- 全部地区标签含义在 **游戏帮助** 中统一说明（与风能、日照等标签并列，见 [供能与能源类型](./04-energy-supply.md)）。

## 月度结算中的资金项

与 [核心循环与时间](./01-core-loop.md) 管道对齐：

| 步骤 | 资金相关处理 |
|------|----------------|
| M1 | 在建项目扣当月建设款；工期 +1 |
| M5 | 月收入入账（售电/供能收入，公式见供能章与数值表） |
| M6 | 设施运维支出 |
| M7 | 原材料支出（与能源类型、事件修饰相关） |
| M8 | 活跃贷款本息扣款 |

**顺序**：建设扣款通常先于或并入当月成本结算，具体顺序在 `features/00-game-state.md`（T13）写死，避免重复扣款。

## 贷款（资金侧摘要）

完整流程见 [01-core-loop.md](./01-core-loop.md#借贷规则)；资金相关要点：

| 规则 | 说明 |
|------|------|
| 申请 | 公司界面，任意月 |
| 并发 | **同时仅 1 笔**未还清贷款 |
| 到账 | 申请成功后资金增加（一次性或首月入账，数值表定） |
| 偿还 | 每月 M8 自动扣本息 |
| 档位 | 随公司等级开放（如 10M / 100M / 1000M 量级，见第 9 章 GDD） |
