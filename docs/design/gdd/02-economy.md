# 资源与经济

## 概述

本章定义小游戏版的**经济资源体系**与**资金侧规则**：**资金**的表示与扣款时机、建设费用、地区成本标签，以及与月度管道的衔接。

**社会价值**见 [社会价值与公司等级](./03-social-value.md)。**首版不做**上游企业收购。

---

## 资金 `funds`

### 数据类型

| 属性 | 规则 |
|------|------|
| 类型 | **带符号浮点数**（实现可用 `float` / `double`，显示可格式化为整数） |
| 可为负 | **允许**；部分玩家操作会导致 **现金流为负**（如连续建设、研发、还贷） |
| 设计意图 | 不强制在 UI 层用「资金不足则禁止一切操作」挡死；下达指令时仍应做**风险提示**，但系统可进入负债态 |

贷款入账、月收入、成本结算均在此基础上加减。

| 资源 | 经济侧角色 |
|------|------------|
| **资金** | 建设、运营、研发、还贷 |
| **社会价值** | 等级、解锁、贷款档位（非直接消费） |

顶栏常驻见 [核心循环与时间](./01-core-loop.md)。

## 资金用途

| 用途 | 扣款时机 | 界面 |
|------|----------|------|
| 建设发电设施 | **下达当月立即扣首月款**；之后每月 M1 扣后续分期 | 城市 |
| 建设区域电网链路 | 同上 | 区域 |
| 建设主干电网 | 同上 | 大地图 |
| 科技研发 | **启动研发时立即扣清总研发费用**（见 [科技研发](./07-tech.md)） | 科技树 |
| 原材料 / 运维 | 按月 M7 / M6 | 自动 |
| 贷款本息 | 按月 M8 | 自动 |

**首版不包含**：收购上游企业。

## 设施建设规则

建设**不是即时完成**；**费用扣款**与**工期**分离理解：

### 流程

```text
玩家下达建设指令
    → 校验（含资金不足时的风险提示；允许扣款后 funds < 0）
    → 立即扣除「首月建设款」（= 总造价 / 工期月数，或数值表指定首笔）
    → 项目进入「在建」，工期计数开始
    → 之后每个「下一月」：M1 扣下一期款 + 工期 +1（直至完工）
    → 完工次月：供能/链路生效
```

### 为何立即扣首月款

避免玩家在同一操作阶段连续下达多项建设，却在月度结算前误以为资金仍充足，导致 **集中爆雷式负现金流**；首笔即时扣款使 **顶栏资金与真实承诺一致**。

### 费用分摊示例

| 项目 | 总造价 | 工期 | 首月（下达时） | 第 2–3 月（M1） |
|------|--------|------|----------------|-----------------|
| 中型火电站（示例） | 30M | 3 个月 | 10M | 各 10M |

### 取消与拆除

在建取消、拆除已建设施的资金处理在 Feature（T15）与数值表定义；供能回落后下月 M9 社会价值 **可减**、收入 **降**，公司 **等级不掉**（见 [03-social-value.md](./03-social-value.md)）。

## 建设与运维的地理差异

| 地区/城市类型 | 建设成本 | 运营成本 |
|---------------|----------|----------|
| 大城市 | 偏低 | 偏低 |
| 中型城市 | 中等 | 中等 |
| 农村 | 偏高 | 中等偏高 |
| 边远地区 | 最高 | 最高 |

## 科技研发扣款

与建设同理，采用 **立即扣款**：

| 规则 | 说明 |
|------|------|
| 触发 | 玩家在科技树确认启动某节点研发 |
| 金额 | 该节点 **总研发费用** 一次性从 `funds` 扣除 |
| 取消 | 研发期间取消则 **全额返还**（旧稿宽松规则，见 [07-tech.md](./07-tech.md)） |
| 资金为负 | 允许扣款后负债；UI 应警告 |

研发进度仍按月推进（M3），与扣款时机无关。

## 月度结算中的资金项

| 步骤 | 处理 |
|------|------|
| M1 | 在建项目扣 **当期** 建设款（首月已在下达时扣，则此处从 **第二个月** 起） |
| M5 | 月收入 |
| M6 | 运维 |
| M7 | 原材料 |
| M8 | 贷款本息 |

**注意**：下达当月若已扣首月建设款，M1 在同一月内 **不应重复扣** 同一期（实现时在 T13 明确去重）。
