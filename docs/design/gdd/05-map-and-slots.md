# 地图与建设位

## 概述

本章定义全国 **大地图拓扑**（**2 都 + 8 区**）、**省壳 / 特大城 / 城市节点** 的行政抽象、**区域差异化** 维度，以及 **通用建设位** 与 **水电 / 核电** 等例外规则，从而形成可读的选址策略。

- **界面参考**：**大地图** 与 **城市建设界面** 见 [META.md §10](../META.md#10-设计参考长期)（**三国志12**）；科技树为行业通例，**不** 借鉴其它作品的城市主界面。
- **取代旧稿**「两都一十一区」：首版全图容量为 **2 座都 + 8 个省壳**（10 个大地图可点击节点），与 [愿景与边界](./00-vision.md)、[社会价值与公司等级](./03-social-value.md) 一致。
- **数值**：本章只写 **结构与定性尺度**；各城 `build_slot_count`、`city_base_social_value` 等具体数字在 GDD 架构 locked 后由 `data/` 精算（见 [04-energy-supply.md](./04-energy-supply.md) 数值工作流）。

## 大地图拓扑

### 整体结构

```text
screen_world_map（全国）
├── 8 ×「区」region（省壳，内含 6–8 座可经营城市）
└── 2 ×「都」metropolis（特大城，各 = 1 座城，不隶属任何区）
```

| 概念 | ID 前缀（配置） | 玩家操作入口 |
|------|-----------------|--------------|
| **区** | `MAP-01` … `MAP-08` | 大地图 → `screen_region` → 选城 → `screen_city_detail` |
| **都** | `MET-A`、`MET-B` | 大地图 → **直达** `screen_city_detail`（无区域界面） |
| **城市** | `CITY-{region}-{nn}` 或 `MET-A` 自身 | 建设、供能、社会价值均 **按城** |

**区 ≠ 都**：都 **不是** 省壳里的「第 N 座城」；与 8 个省节点 **平级** 画在大地图上（见 [01-core-loop.md](./01-core-loop.md)）。

### 与旧稿差异

| 旧稿（§12） | 首版定稿 |
|-------------|----------|
| 两都 **+ 十一** 常规区 | 两都 **+ 八** 省壳（`00-vision` / `03`） |
| 每区「至少」中心城市 + 农村 | 每省 **6–8** 城，且 **有且仅有 1 个中心城市**；其余节点逐省差异化配置 |

### 全图规模（定性）

| 项 | 规则 |
|----|------|
| 大地图可点击节点 | **10**（8 区 + 2 都） |
| 可经营城市总数（V 级全开） | **≈ Σ(各省 6–8) + 2**；例：8 省平均 7 城 → 约 **56** 座城 + 2 都 ≈ **58** 座（以表为准） |
| 跨区联络 | 主干电网连接 **枢纽城**（省中心、都、超级水电；见 [06-grid.md](./06-grid.md)） |

### 源于现实（地图拓扑）

本游戏 **来源于现实**，机制须 **模仿现实** 中被广泛验证的结构；玩法可简化，但 **不采用** 现实中罕见的拓扑当作默认。

| 现实 | 游戏中的取舍 |
|------|----------------|
| 省区之间多为 **多邻接网状**（一方形区域常邻多国/多省） | 大地图用 **`adjacent_region_ids` 网状** 为主；度数 **1～4+** 灵活配置 |
| **链式** 走廊（仅邻一国）在现实中 **存在但不多** | 允许个别省 **仅 1 个邻省**（如 `MAP-02` 占位），**不** 把「全国排成单链」当作默认模型 |
| 特大城与周边省 **多点接壤** | **都** 宜 **2～4** 邻省，作电网与物流枢纽 |
| 地理相连才便利组网 | 各等级可经营区须 **单一连通块**（见下节） |

后续新增省界、解锁顺序或美术换皮，先问：**现实里是否常见？** 再落表。

### 可经营区必须大地图相连（已决）

**设计核心**：任意公司等级下，**当前已解锁且可经营** 的省壳与 **都** 节点，在邻接图上必须组成 **一个连通块**，便于玩家拉 **区域线 / 主干** 组网。

| 规则 | 说明 |
|------|------|
| **网状邻接** | 省/都之间是 **无向网**（**非** 单链）：一省可只邻 **1** 省，也可邻 **多** 省/都；度数灵活 |
| **数据为准** | `region_base.adjacent_region_ids` 为 **唯一真理**；美术按表画省界，禁止与表冲突 |
| **解锁扩展** | 本档 **新开放** 的每个节点，至少与 **当前可经营集合** 中 **一个** 节点邻接 |
| **换序** | 可改解锁顺序（如先开 `03～08`），须 **同步改邻接** 且通过各档连通验收 |
| **验收** | 落表后检查：I～V 各档「可经营节点集」均为 **单连通分量** |

**与电网**：连通是 **地图拓扑**；相邻不自动送电，只保证 **可以** 组网（见 [06-grid.md](./06-grid.md)）。

#### 网状占位原则（与上节一致）

| 原则 | 说明 |
|------|------|
| **度数差异** | 枢纽省 / **都** 可多邻（3～4）；边区、走廊省可 **单邻** 或双邻 |
| **都的角色** | `MET-A` / `MET-B` 宜邻 **2～4** 省，作跨区电网枢纽（非链上单点） |
| **入门区** | `MAP-01` 示例邻 **2** 省，避免「一条线捅到底」 |
| **全图** | V 级全开时 8 省 + 2 都在整网上 **连通** |
| **无链式硬约束** | **不要** 把 8 省排成单链当作规则；仅 **解锁阶梯 + 连通** 为硬约束 |

#### 首版邻接占位（网状，与解锁表一致）

**示意图**（边 = 接壤；位置仅示意）：

```text
              MAP-08
                |
           MAP-07—MAP-06
                |    \
          MET-B—MAP-05—MAP-04
           /  \    |    /
      MAP-03—MET-A—MAP-02
           \       |    /
              MAP-01
         （I：仅城内 CITY-START）
```

**邻接表**（`adjacent_region_ids`）：

| 节点 | 接壤 |
|------|------|
| `MAP-01` | `MAP-02`, `MAP-03` |
| `MAP-02` | `MAP-01`, `MET-A` |
| `MAP-03` | `MAP-01`, `MAP-04`, `MET-A` |
| `MET-A` | `MAP-02`, `MAP-03`, `MAP-04`, `MAP-05` |
| `MAP-04` | `MAP-03`, `MET-A`, `MAP-05`, `MET-B` |
| `MAP-05` | `MET-A`, `MAP-04`, `MAP-06`, `MET-B` |
| `MET-B` | `MAP-04`, `MAP-05`, `MAP-07` |
| `MAP-06` | `MAP-05`, `MAP-07`, `MAP-08` |
| `MAP-07` | `MAP-06`, `MET-B`, `MAP-08` |
| `MAP-08` | `MAP-06`, `MAP-07` |

| 等级 | 可经营大地图节点（累计） | 本档新增 | 网状连通 |
|------|--------------------------|----------|----------|
| I | `MAP-01` 内 1 城 | — | 单点 |
| II | `MAP-01` | 全省 | 单省 |
| III | `MAP-01`, `MAP-02`, `MET-A` | `MAP-02`, `MET-A` | 三角连片 |
| IV | 上 + `MAP-03`～`05` | 三省 | 扩网连片 |
| V | 上 + `MET-B`, `MAP-06`～`08` | 1 都 + 三省 | **全图网** |

换皮可改美术坐标；**不得** 破坏各档连通性；改邻接须重跑验收。

## 行政节点类型

省内每座可操作城市配置 `node_type`（`region_nodes` 表）：

| `node_type` | 含义 | 建设成本 / 运维（相对） | 典型策略角色 |
|-------------|------|-------------------------|--------------|
| `core_city` | **有且仅一** 座 / 省 | 偏低 | 可建核电、高需求、区域枢纽 |
| `ordinary_city` | 常规城市 | 中等 | 均衡装机 + 受电 |
| `rural` | 农村点 | 建设偏高、运维中等偏高 | **建设位数量偏多**、低成本绿电基地 |
| `frontier_town` | 边陲小镇 | 最高 | 高风/光潜力但造价高；外送依赖电网 |
| `metropolis` | **都** 专用（MET-A/B） | 接近 `core_city` 略优 | 单城大体量；槽位 **多于** 普通中心城 |

**省壳结构约束**（每 `MAP-xx`）：

1. **恰好 1** 座 `core_city`（`is_core_city = true`）。
2. 其余为 `ordinary_city` / `rural` / `frontier_town`，合计 **5–7** 座，使全省 **6–8** 座。
3. **禁止** 8 省共用同一套模板；节点数与类型组合 **逐省** 在 `data/` 配置，尽量各省不同。

## 公司等级与可经营范围

可经营范围以 [03-social-value.md](./03-social-value.md) 为准；本章补 **地图语义**：

| 等级 | 累计可经营（地图） | 说明 |
|------|-------------------|------|
| **I** | **1 城市** | 入门仅 **`CITY-START`**（建议为 `MAP-01` 中心城）；同省其它城 **灰显不可经营** |
| **II** | **+1 区** | 解锁第一个完整省壳（如 `MAP-01` 全境 6–8 城） |
| **III** | **1 都 + 2 区** | 解锁第一座都（如 `MET-A`）+ **2** 个省壳全境 |
| **IV** | **1 都 + 5 区** | 在 III 基础上再 +3 省壳（累计 1 都 5 区） |
| **V** | **2 都 + 8 区** | 全图可经营 |

| 状态 | 大地图 | 区域/城市界面 |
|------|--------|---------------|
| 未解锁 | 节点 **灰显不可点** | 不可进入 |
| 已解锁省壳、但 I 级仅 1 城 | 省可点进 `screen_region` | 仅 `CITY-START` 可建设；其它城 **只读**（供能/标签可见，不可下单建设） |
| 已解锁且可经营 | 正常 | 全部可操作城可建设 |

**解锁顺序**：由 `region_base.unlock_company_level` 配置；**占位推荐**（可换皮，实现以表为准）：

| 公司等级 | 累计可经营 | 本档 **新开放** 大地图节点（占位） |
|----------|------------|-----------------------------------|
| **I** | 1 城 | `CITY-START`（`MAP-01` 中心城） |
| **II** | 1 区 | 省壳 **`MAP-01`** 全境 |
| **III** | **1 都 + 2 区** | **`MET-A`** + 省壳 **`MAP-02`**（相对 II 新增 1 都 1 省） |
| **IV** | **1 都 + 5 区** | **`MAP-03`～`MAP-05`**（相对 III 再 +3 省） |
| **V** | 2 都 + 8 区 | **`MET-B`** + **`MAP-06`～`MAP-08`** |

> **说明**：III 的「1 都 2 区」为 **累计**。调整 `unlock_company_level` 时须同时改 **`adjacent_region_ids`**，保证各等级可经营集合 **大地图相连**（见上节）。

## 全图清单（占位骨架）

> 展示名用 **占位**；实现以 `region_id` / `city_id` 为准。节点数为 **策划目标**，精算时允许 ±1 但须保持「每省 6–8、有且仅一中心城」。

### 两都

| ID | 占位名 | `node_type` | 省内城市数 | `base_demand_mw` 建议范围 | 差异化摘要（定性） |
|----|--------|-------------|------------|---------------------------|-------------------|
| `MET-A` | 特大城·甲 | `metropolis` | **1**（自身） | **1800–2200**（建议默认 2000） | 高需求、核电/主干枢纽；建设位中等、火电运维中等 |
| `MET-B` | 特大城·乙 | `metropolis` | **1** | **1600–2000**（建议默认 1800） | 与甲 **不同** 资源标签组合（例：光丰富、风一般）；建设位可略少但光伏潜力高 |

### 八区（省壳）

| ID | 占位名 | 目标城数 | 行政单位组合（固定 1 中心） | 差异化主轴（须与邻省可区分） |
|----|--------|----------|------------------------------|------------------------------|
| `MAP-01` | 省·一 | 6 | 1 中心 + 3 常规 + 1 农村 + 1 边陲 | 入门省；`CITY-START` = 中心城；风一般、化石能源利好火电 |
| `MAP-02` | 省·二 | 7 | 1 中心 + 2 常规 + 3 农村 + 1 边陲 | 风 **丰富** + 农村点多 → 风电基地 |
| `MAP-03` | 省·三 | 8 | 1 中心 + 2 常规 + 3 农村 + 2 边陲 | 最大省壳；江河多 → 常规水电点多 |
| `MAP-04` | 省·四 | 6 | 1 中心 + 4 常规 + 1 农村 | 光 **丰富**、建设成本整体中等 |
| `MAP-05` | 省·五 | 7 | 1 中心 + 1 常规 + 2 农村 + 3 边陲 | 边陲小镇多、造价高、风光位多但难建 |
| `MAP-06` | 省·六 | 8 | 1 中心 + 3 常规 + 2 农村 + 2 边陲 | 化石能源 + 高需求中心城 → 火电枢纽省 |
| `MAP-07` | 省·七 | 6 | 1 中心 + 2 常规 + 2 农村 + 1 边陲 | 省际联网价值高（主干战略意义）；风/光均衡 |
| `MAP-08` | 省·八 | 7 | 1 中心 + 3 常规 + 2 农村 + 1 边陲 | 后期综合省；资源 **无明显** 单项极端，考验调配 |

每省在 `region_nodes` 中展开具体 `city_id` 列表（例：`CITY-MAP-02-01` …）；**不在 GDD 正文逐城列 MW**，避免与 data 双源。

## 区域差异化

区域 **禁止换皮**：至少在三类维度上 **可区分**：

| 维度 | 配置位置 | 作用 |
|------|----------|------|
| **资源标签** | 省级或城市级 | 风 `wind_normal` / `wind_rich`；光 `solar_normal` / `solar_rich`；`fossil_energy`（见 [04-energy-supply.md](./04-energy-supply.md)、[02-economy.md](./02-economy.md)） |
| **造价与运维** | `node_type` + `build_cost_modifier` / `operation_cost_modifier` | 同设施在不同城造价不同 |
| **建设位数量** | 每城 `build_slot_count` | 限制同城设施总数；农村位多、中心城位少，引导跨城布局 |
| **临水** | `has_river` | 可否在本城选建 **常规水电**；地图须标注（见下节） |
| **电网价值** | 区域拓扑 + 邻省关系（定性） | 某些省更适合当 **外送枢纽**（细节 [06-grid.md](./06-grid.md)） |
| **社会价值潜力** | `city_base_social_value` | 中心城高、农村低；与满足率、环保上限相乘（[03-social-value.md](./03-social-value.md)） |

### 社会价值基数（定性尺度）

与旧稿基准同量级，供 data 对齐（**非最终数**）：

| `node_type` | `city_base_social_value` 参考量级 |
|-------------|----------------------------------|
| `rural` | ~100 |
| `ordinary_city` | ~500 |
| `core_city` | ~3000 |
| `metropolis`（都） | ~3500–4500（**高于**普通中心城） |

### 策略差异（设计意图）

| 误区 | 定稿意图 |
|------|----------|
| 中心城 = 设施铺满 | 中心城 **建设位少**、需求高，适合火电/核电 + 受电 |
| 农村 = 劣质区 | 农村 **建设位多**，适合作为 **绿电输出基地** |
| 全图同质 | 有的省火电便宜，有的省风/光翻倍，有的省江河多 |

## 建设位系统

### 设计思路

- **地图与城建界面**（三国志12）：固定数量 **通用建设位**；已建设施显示在位上；**空位** 可点选要建什么。
- **策略**：不同城市 **`build_slot_count` 不同**，限制同城无限铺场，迫使 **跨城布局** 与 **区域电网** 协作。

**首版不做**「风位只能建风、光位只能建光」的分类型槽。

### 科技等级、建造列表与科技驱动同步

科技树为 **AoE2 式分页平铺**（[07-tech.md](./07-tech.md)）；节点 **点亮** 后更新每条设施线的 **可建最高等级** `facility_build_tier_max`（取该线已点亮节点中的 **最高 tier**）。

| 场景 | 规则 |
|------|------|
| **点空位 → 建造列表** | 每种已解锁设施线 **只列出当前最高可建等级** 一项。例：科技已到火电 4 级 → 列表仅有「4 级火电」，**不** 出现 3 级及以下 |
| **未解锁设施线** | 该类型 **整线不出现在** 列表（非灰显占位） |
| **城内已有低等级 / 待改造设施** | **不显示** [升级] 按钮；研发节点 **完成当月** 由系统 **自动同步**（见下） |
| **同步 vs 新建** | 同步 **不占用新建设位**、**无** 玩家确认、**无** 升级工期队列、**不收** 升级费（仅新建仍走建设费/工期） |

#### 科技驱动同步（已决）

研发节点 **完成** 时（M3 完成拍，[01-core-loop.md](./01-core-loop.md)），对 **全图已解锁且可经营** 范围内、**已完工** 且匹配该节点效果的设施实例 **立即** 写入目标配置：

| 节点类型（示例） | 同步对象 | 写入内容 |
|------------------|----------|----------|
| `thermal_N` 等发电线 **点亮** | 该线已完工设施 | 升至 **tier N** 配置行 |
| `eco_thermal` / `eco_nuclear` | 火/核 | **即时** `is_eco = true` |
| `storage_system_1`（储能系统·I） | — | 全局 `storage_mult`（[04](./04-energy-supply.md)、[07-tech.md](./07-tech.md)） |
| `uhv_transmission` | 已完工 `backbone_link` | `loss_mw` 升为特高压后档（[06-grid.md](./06-grid.md)） |

```text
火电·IV 点亮（公司 IV、研发完成当月）
  → 新建列表：仅「火电·IV」
  → 城内旧「火电·III」：自动变为 IV 配置（仍占原建设位）
```

**首版不做** 玩家手动点设施 [升级]；避免操作繁复。UI 可在同步后 **Toast / 界面内提示**「X 座设施已随科技更新」。

每行 `facility_config` 含 **产能量**、**运行费用**、建设费用等（字段语义见 [04-energy-supply.md](./04-energy-supply.md#设施属性与展示产能)）。

### 建造列表与设施详情（UI 约定）

| 场景 | 必显字段 |
|------|----------|
| **建造列表**（点空位） | **设施名-lv**、**建设费用**、**产能量**、**运行费用** |
| **点按城内设施** | **设施名-lv**、**产能量**、**运行费用**；另加常显 **状态图标**（在建 / 运行等；**无**「升级中」） |

列表与详情中的数值 **直接读当前 tier 或升级目标行配置**；升级后产能量、运行费用 **以表为准**（可升可不变），**不** 使用「铭牌×2」类隐含倍率。

### 通用建设位

| 规则 | 说明 |
|------|------|
| 一设施一位 | 每座发电设施（火电/水电/风电/光伏/核电）占用 **1** 个通用位；**在建即占位** |
| 空位建造 | 点空位打开列表：**已解锁设施线** + **仅最高可建 tier** + **满足选址** |
| 位满 | `occupied_slots >= build_slot_count` 时 **不可新建**；提示「建设位已满」 |
| 科技同步 | 见上节；发电 **·II～V** / 环保等 **点亮即改实例**（表驱动），**不新增位** |
| 计数展示 | 城市界面显示 **已用/总数**（如 `3/5`），不按设施分槽统计 |

### 数量级（定性，供 data 落表）

| `node_type` | `build_slot_count`（典型） |
|-------------|---------------------------|
| `core_city` | 3–4 |
| `ordinary_city` | 4–5 |
| `rural` | 5–7 |
| `frontier_town` | 4–6 |
| `metropolis` | 5–6（可略高于普通中心城） |

具体整数 **逐城** 配置，保持省际差异。

### 设施选址例外（不占「分槽」，走规则校验）

以下约束在 **选设施时** 判断，**不** 通过单独槽位类型实现：

| 设施 | 选址规则 |
|------|----------|
| **常规水电** | 仅 `has_river = true`（**临水**）的城市可出现在建造列表中 |
| **核电** | 仅 `is_nuclear_eligible = true` 的城市（**省内中心城** `is_core_city` 或 **都** `metropolis`）；且该城 **已有核电数量 < 1**（全游戏语义：**每城至多 1 座核电**） |
| 风电 / 光伏 / 火电 | 有空位 + 科技解锁即可；出力仍受 `wind_tag` / `solar_tag` / `fossil_energy` 等影响（[04](./04-energy-supply.md)） |
| **超级水电** | 不占城内建设位；全图大地图 **2** 槽（见下） |

```text
点空位 → 建造列表
    → 每设施线取 facility_build_tier_max（仅最高 tier 一项）
    → 过滤：通用位未满 ∧（水电→临水；核电→有资格且未满 1）
    → 玩家选一项 → 造价/工期确认（02-economy）
```

### 槽位占用与释放

```text
下达建设
    → 校验：通用位未满 + 设施选址例外 + 等级/科技
    → 占用 1 个 build_slot（在建即占用）
完工 → 位仍占用
拆除（若有，T15）→ 释放位；下月 M4/M9 重算
```

### 界面与地图标注（玩法层）

GDD 约定 **玩家可见** 行为；线框与组件树在 **UI Spec**（三国志12 式，见 [META.md](../META.md)）。

| 场景 | 约定 |
|------|------|
| **大地图 / 区域界面** | 布局参考三国志12；`has_river` 城市在 **城市名旁** 显示 **临水** 标签 |
| **城市建设界面** | 三国志12 式位图：已建设施、空位；**无** 设施升级按钮（科技完成自动同步） |
| **建造列表** | 弹层或侧栏；仅 **最高可建 tier**；列：**设施名-lv、建设费用、产能量、运行费用** |
| **设施详情** | 点按城内设施；**设施名-lv、产能量、运行费用** + 状态图标 |
| **科技树界面** | AoE2 式分页平铺（T31 / `07-tech`）；与城建界面分离 |

### 战略级建造位（大地图）

在全国 `screen_world_map` 操作的 **全图限量** 工程（不占城内风光槽）：

| 工程 | 全图数量 | 建造界面 | 备注 |
|------|----------|----------|------|
| **超级水电** | **2** | 大地图选固定槽位 | V 级科技；单座约 **2 省** 联网体量（定性，[04](./04-energy-supply.md)） |
| **主干电网** | 按链路 | 大地图 | 不占发电槽；T08 |
| **大型水利（若与超级水电区分）** | 并入超级水电或单列 | 大地图 | 首版 **2 座超级水电** 已覆盖「大型水利」战略定位 |

常规水电占用城内 **1 个通用建设位**，且须 **临水**；不占用超级水电全图槽。

| 设施类型 | 选址约束 |
|----------|----------|
| 风电 / 光伏 / 火电 | 通用位未满 + 科技解锁；风/光受资源标签修正 |

单城 **`build_slot_count`** 与 `base_demand_mw` 一并由 data 精算，从结构上避免单城无限铺场。

### `region_base`（每省壳 / 都一行）

### `region_nodes`（每城一行）

| 字段 | 说明 |
|------|------|
| `city_id` | 全局唯一 |
| `region_id` | 所属省壳；都则填 `MET-A` / `MET-B` |
| `node_type` | 见上文 |
| `is_core_city` | 每省 **恰一** true |
| `has_river` | 临水；可否选建常规水电；驱动地图 **临水** 标注 |
| `is_nuclear_eligible` | 可否选建核电（中心城或都） |
| `build_slot_count` | 通用建设位上限 |
| `nuclear_count` | 运行时字段：当前城已建核电数（策划表可不存，逻辑上限 1） |
| `city_base_social_value` | M9 公式基数 |
| `base_demand_mw` | 静态需求（[04](./04-energy-supply.md)）；按 `city_type` 从范围档位选值（见 `data/schemas/region-and-city.md`） |
| `wind_tag` / `solar_tag` | 可覆盖省级默认 |
