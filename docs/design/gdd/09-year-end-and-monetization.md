# 公司经营与商业化

## 概述

本章定义：

1. **公司经营界面**：大理石式 **经营快照 + 近月流水**（**无年报**）。
2. **借贷**：公司界面任意月申请；**按等级 I–V 梯度**；单笔并发；M8 还款。
3. **岗位**：**财务总监**（6 元买断）+ **工程总监**（30 元礼包内）；无 IAP 时 **弱 baseline**。
4. **激励广告**：三类奖励；**单局最多 10 次**；失败重开新局重置。
5. **队列上限**：研发 **单队列**；建设 **全局最多 3 在建**（工程总监 **+1**）。

参考《大理石时代》**Polis / 城市统计**：**随时打开、看当下**，无 12 月汇总、无年度弹窗。

| `loan_id` | 解锁等级 | 本金 | 期数 | 总利息 | 月供约 |
|-----------|----------|------|------|--------|--------|
| `loan_1` | I | 30 | 12 | 3 | 3 |

## 激励广告

### 定位

首发及后续均可用的 **可选激励视频**（rewarded）；**非**抽卡、**非**随机池。与 **插屏/横幅** 区分：本节三类为 **玩家主动点击** 换取奖励。

### 单局次数上限

| 规则 | 说明 |
|------|------|
| 初始 | 新游戏开始时 `ads_remaining = 10` |
| 消耗 | 每次 **完整观看** 激励视频并成功回调 → `ads_remaining -= 1` |
| 用尽 | `ads_remaining = 0` 时 **隐藏或灰显** 全部激励入口 |
| 重置 | **仅** 本局 **Game Over 后开新局** 重置为 10；**继续存档** 不重置 |
| 通关后新局 | 同失败重开，重置为 10 |
| **免广告期** | 30 天免强迫广告 **不增加** 激励次数；**仍为 10 次/局** 硬顶 |
| **不可购买次数** | **无** IAP 或月卡可追加激励额度；用尽只能等 **下一局** |

**设计意图**：激励是 **有限次安全阀**（10 次硬顶），避免无限刷资金/秒完工 **击碎** 单局平衡；与 **3 在建 + 单研发队列** 形成张力。**免广告只去掉强迫打断**，不改变本局激励配额。

### 三类奖励

| 类别 ID | 名称 | 效果 | 前置 |
|---------|------|------|------|
| `ad_cash` | **资金补助** | `funds +=` 按公司等级表（见下） | 无 |
| `ad_instant_build` | **建设加速** | 玩家 **指定 1 项** 全局在建 → **立即完工**（次月 M1/M2 起生效规则与正常完工一致） | 至少 1 项在建 |
| `ad_instant_research` | **研发加速** | 当前 **唯一** 在研项目 → **立即点亮**（当月生效） | 有在研项目 |

| 规则 | 说明 |
|------|------|
| 互斥 | 每次观看 **只选一类** 一种奖励 |
| 与事件 | 激励完工 **不** 绕过 `freeze_build` 等 **新建** 冻结；仅加速 **已在建/已在研** |
| 与破产 | 激励资金 **可** 用于当月回正，仍按月末快照计破产 |

### `ad_cash` 梯度（初版统筹）

| 公司等级 | 单次奖励（万） |
|----------|----------------|
| I | 15 |
| II | 25 |
| III | 40 |
| IV | 65 |
| V | 90 |

约为同等级 **单档贷款本金** 的 **50% 左右**，不足以替代经营，可解 **一次** 现金流燃眉之急。

### 存档字段

- `ads_remaining`（0–10）
- `ad_free_until`（Unix 或游戏内日期；30 元礼包授予，见下）

## 商业化（分阶段）

### 阶段

| 阶段 | 变现 |
|------|------|
| **首发** | **激励广告** + 插屏/横幅（工程礼包未开放时全员可见） |
| **后续** | 上表 + **两档 IAP**（下表） |

除 **广告** 与两档 IAP 外：**无** 抽卡、随机池、第三档礼包链。

### SKU（两档）

| SKU | 类型 | 价格 | 内容 |
|-----|------|------|------|
| `iap_cfo` | **一次性买断** | **6 元** | 财务总监 **完整版** |
| `iap_pe_bundle` | **一次性买断** | **30 元** | **工程总监完整版** + **30 天免强迫广告** |

| 规则 | 说明 |
|------|------|
| 30 元礼包 | **非**订阅自动续费；一次性购买，写入 `ad_free_until = now + 30d` |
| 免广告范围 | 30 天内 **免插屏 + 免横幅** |
| 激励次数 | **不变**：仍为 **10 次/局**；**不因** 购买礼包而增加 |
| 激励可用性 | 免广告期内 **仍可主动看** 激励换奖励（若 `ads_remaining > 0`） |
| 到期 | 恢复插屏/横幅；工程总监岗位 **永久保留** |
| 重复购买 | 30 元礼包 **可重复买** 仅用于 **续 30 天免强迫广告**（工程总监已拥有则 **只延长** `ad_free_until`，不叠岗位） |

## 总监岗位

### 定位

**固定双槽**（`screen_company` → 「岗位」），非收集角色。**研发** 侧节奏由 **单队列 + lit 预算 + 激励研发加速** 承担；**建设** 侧由 **全局 3 在建 + 工程总监** 承担——与全图多城建设量匹配。

### 效果表

| 岗位 | `role_id` | baseline（弱） | 完整版（IAP） |
|------|-----------|----------------|---------------|
| **财务总监** | `cfo` | 贷款利息 **−5%**；原材料 **−3%** | 利息 **−10%**；原材料 **−8%**；贷款 **+1 档** |
| **工程总监** | `pe` | **无** 数值加成（槽位常显「标准编制」） | **全局** 新下达建设 **工期 −1 月**（下限 1）；**最大在建 +1**（3→**4**） |

| 规则 | 说明 |
|------|------|
| 工程总监工期 | 作用于 **设施 + 区域链 + 主干**；**下限 1 月** |
| 工期 −1 来源 | **仅** 工程总监（完整版）与 **激励 `ad_instant_build`（秒完工）**；**科技树不提供** 施工工期减免（见 [07-tech.md](./07-tech.md)） |
| 工程总监在建 | 仅 **完整版** 提升上限；baseline 仍为 **3** |
| 研发 | **无** 工程/财务总监 **常驻** 研发 modifier；研发卡点用 **广告 instant research** 或 **科技树 `eng_*`** |
| 槽位 UI | **始终显示**；未买断标注可升级 |

## 队列与岗位协同（跨章摘要）

| 系统 | 规则 | 章节 |
|------|------|------|
| 研发 | **同时仅 1 项** 在研 | [07-tech.md](./07-tech.md) |
| 建设 | **全局最多 3 在建**（工程总监 **4**） | [02-economy.md](./02-economy.md) |
| 激励广告 | **10 次/局**；资金 / 秒完工 / 秒点亮 | 本节 |
| 贷款 | 单笔并发 | 本节 |

```text
  典型卡点：3 项在建已满 → 等推月 or 看广告秒完一项 or 买工程总监扩到 4
            科技在研中 → 只能排队 or 看广告秒点亮 or 取消换退款
            现金紧     → 贷款 or ad_cash（还剩 N/10 次）
```

## 已决事项

| 议题 | 决策 |
|------|------|
| 技术总监 | **改为工程总监**；**施工 −1 月** + **在建 +1**（完整版） |
| 研发岗位 | **不设** 常驻研发总监；研发靠队列 + 广告 + 科技树 |
| 研发队列 | **单队列**（同时 1 项在研） |
| 在建上限 | **全局 3**（工程总监 **4**） |
| 激励广告 | **三类**、**单局 10 次硬顶**（免广告期不追加）；失败重开重置 |
| 施工工期 −1 | **仅** 工程总监 + 激励秒完工；**科技树无** |
| 30 元礼包 | **工程总监 + 30 天免强迫广告** |
