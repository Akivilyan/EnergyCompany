# 核心循环与时间

## 概述

本章定义**五类界面**及其层级关系、**核心玩法循环**、**月度结算管道**、**关键节点反馈**，以及**公司界面内的战略与借贷**规则。

**取代旧稿「四层结构」**（地区 / 大地图 / 公司 / 年度战略）：不再有独立的「年度战略界面」；贷款等战略功能集中在**公司界面**，**任意月份**可操作。

前提见 [愿景与边界](./00-vision.md)：**静态操作 + 按月推进**；不做每月固定经营结果弹窗。

---

## 界面体系（五类）

### 层级关系

```text
  ┌─────────────────────────────────────────────────────────────┐
  │  大地图  screen_world_map                                    │
  │  · 选区域/进区域 · 超大水电/核电（固定区位）· 全图少量建造位      │
  │  · 区域间线路（连接各区域核心城市）                             │
  └───────────────────────────┬─────────────────────────────────┘
                              │ 进入已解锁区域
                              ▼
  ┌─────────────────────────────────────────────────────────────┐
  │  区域界面  screen_region                                     │
  │  · 区域内城市之间的线路铺设                                   │
  └───────────────────────────┬─────────────────────────────────┘
                              │ 进入城市
                              ▼
  ┌─────────────────────────────────────────────────────────────┐
  │  城市详细建设界面  screen_city_detail   ← 最常停留 · 下一月主入口 │
  │  · 发电设施 · 本地建设位 · 供能/在建 · 非弹窗式进度提示          │
  └───────────────────────────┬─────────────────────────────────┘
                              │
        ┌─────────────────────┼─────────────────────┐
        ▼                     ▼                     ▼
  screen_tech_tree      screen_company         （返回大地图）
  科技树界面             公司界面
  任意月可进             任意月可进；战略与借贷
```

**全局界面**（与地图层级平级，随时可切换）：

| 界面 ID | 名称 | 可达性 |
|---------|------|--------|
| `screen_tech_tree` | 科技树 | **任意月份**可进入、查看、研发操作 |
| `screen_company` | 公司 | **任意月份**可进入；可提交战略选项（贷款等，见借贷规则） |

---

### 城市详细建设界面 `screen_city_detail`

**定位**：单座城市的建设与运营主战场；玩家停留时间最长。

| 类别 | 行为 |
|------|------|
| 建设 | 在本城建设位上建设发电等设施（见 [地图与建设位](./05-map-and-slots.md)） |
| 查看 | 在建项目与工期；本市供能满足率；运营概况 |
| 推进时间 | **`下一月`** 主入口（右下角主按钮） |

**信息架构（玩法层）**：

| 区域 | 内容 |
|------|------|
| 顶栏 | 资金、社会价值、当前年月 |
| 主区域 | 当前城市场景与建设位 |
| 常驻/悬浮提示区 | **科技研发完成**、**供能达到 100%** 等：用界面内提示呈现，**不用全屏弹窗**（见「关键节点反馈」） |
| 其它悬浮 | 事件入口、在建列表、帮助等 |
| 导航 | 返回区域界面、大地图；进入科技树、公司界面 |
| 主按钮 | **`下一月`** |

---

### 区域界面 `screen_region`

**定位**：在同一**区域**内，连接多座城市（核心城市、农村、边区等）的电网。

| 类别 | 行为 |
|------|------|
| 组网 | 在**区域内部城市之间**铺设线路（区域电网链路） |
| 导航 | 进入某一城市的 `screen_city_detail` |
| 查看 | 区域级供能/联通概况（细则见 [电网](./06-grid.md)） |

**不负责**：跨区域的骨干线路（在大地图）；单城发电站细节（在城市界面）。

---

### 大地图界面 `screen_world_map`

**定位**：全国宏观布局；战略级设施与跨区联络。

| 类别 | 行为 |
|------|------|
| 选区 | 进入**已解锁**区域 → 区域界面；**未解锁区域仅灰显，不可点击**（无只读预览） |
| 战略设施 | **超大水电站**、**核电站**：作为地图上的**固定区域/固定建造位**（全图仅提供**少量**建造位，非逐城铺满） |
| 跨区线路 | 铺设**区域间**线路，连接各区域的**核心城市**（主干电网，见 [电网](./06-grid.md)） |
| 查看 | 区域标签、供能概况、区域间联通、事件相关预告 |

**不负责**：区域内城市间细线（在区域界面）；普通城市火电/风光建站（在城市界面）。

---

### 科技树界面 `screen_tech_tree`

**定位**：长期科技路线。

| 规则 | 说明 |
|------|------|
| 可达性 | **任意月份**可打开并完成研发相关操作 |
| 完成反馈 | 研发完成**不触发全屏弹窗**；在城市界面或其它常驻区域展示完成状态（见 [科技研发](./07-tech.md)） |

---

### 公司界面 `screen_company`

**定位**：公司经营中枢；财务、社会价值、岗位配置、**战略与借贷**及执行跟踪。

**任意月份**均可进入并完成下表操作（无「仅 1 月可提交」限制）。

| 类别 | 行为 |
|------|------|
| 经营总览 | 现金流、资产、负债、月度/年度记录 |
| 社会价值 | 明细与等级进度（见 [社会价值](./03-social-value.md)） |
| 岗位 | 财务总监、技术总监等配置（见 [年度战略与商业化](./09-year-end-and-monetization.md)） |
| **借贷** | 申请贷款（档位随公司等级）；细则见下「借贷规则」 |
| 战略执行跟踪 | 当前贷款：已还期数、剩余期数、到期月 |

#### 借贷规则

| 规则 | 说明 |
|------|------|
| 入口 | 仅在公司界面发起（无独立年度战略屏） |
| 时间 | **任意月份**可申请 |
| **并发上限** | 同一时间 **有且仅有 1 笔** 贷款处于未还清状态；已还清后方可再申请新贷款 |
| 还款 | 按月自动扣款，纳入月度管道 M8（见 [资源与经济](./02-economy.md)、第 9 章 GDD） |

**与旧稿差异**：不再有独立「年度战略界面」；贷款不绑定固定月份。**首版不做收购**（见 [资源与经济](./02-economy.md)）。

## 核心玩法循环

```text
  1. 大地图选已解锁区域 → 区域界面组网 → 城市界面建设/查看
     （或在大地图做跨区线路、超大水电/核电）
  2. 任意月可开科技树研发；公司界面查看经营、申请或跟踪贷款（无未还清贷款时方可新贷）
  3. 点击「下一月」
  4. 月度结算管道 M1–M13
  5. 若公司升级 → 大事件弹窗；科技完成/供能100% → 界面内提示，不弹窗
  6. 继续建设、组网或应对事件波动
```

## 时间推进规则

| 规则 | 说明 |
|------|------|
| 基本单位 | **月**；顶栏显示年+月 |
| 静态操作 | 浏览、建设、研发、查看公司/科技时时间不流逝 |
| 主动推进 | 点击 **`下一月`** 前进 1 个月；主入口在 **城市详细建设界面** |
| 战略与借贷 | 公司界面**任意月**可提交；**同时最多 1 笔**未还清贷款 |
| 12 月 | 月度管道汇总**年度报表数据**（M13）；具体展示 UX 见开放问题 |

## 月度反馈策略

- **不做**每月固定「上月经营结果」全屏弹窗。
- 资金、社会价值、供能变化通过顶栏与各界面常驻信息感知。
- 节奏来自 **公司升级大事件**、**事件系统**、**借贷决策** 与建设进度。

---

## 关键节点反馈

### 全屏弹窗（大事件，引发关注）

| 类型 | 条件 |
|------|------|
| **公司等级提升** | M10 检视后升级 |
| **政策/市场类事件** | 对资金、收入或研发有显著干预时（见 [事件系统](./08-events.md)） |
| **大型工程竣工** | 超大水电、核电等战略工程完工（是否弹窗可与 UI 再收敛；默认保留） |

同月仅 **公司升级** 必走大弹窗；若与事件同月，**先升级弹窗**，事件弹窗排队或次月呈现（实现/UI 细化）。

### 界面内提示（不弹窗）

| 类型 | 展示原则 |
|------|----------|
| **科技研发完成** | 科技树节点点亮 + 城市/顶栏等区域常驻提示；**不用**全屏插画 |
| **供能满足率 100%** | 当前城市或区域供能 UI 达标态/徽章；**不用**全屏插画 |

## 顶栏核心资源

| 资源 | 说明 |
|------|------|
| 资金 | 建设、运维、研发、还贷、战略投入等 |
| 社会价值 | 等级、解锁、科技门槛 |

顶栏以 **城市详细建设界面** 为主承载；其它界面是否复用顶栏，在 UI Spec 统一。

## 已决事项（2026-05-19）

| 议题 | 决策 |
|------|------|
| 界面结构 | **五类**：城市详细建设、区域、大地图、科技树、公司；**废除**旧四层及独立年度战略屏 |
| 科技完成 / 供能 100% | **不弹窗**；主界面其它区域展示 |
| 公司升级 | **大事件全屏弹窗** |
| 未解锁地区 | 大地图 **灰显不可点** |
| 科技树 / 公司 | **任意月**可进入；战略（借贷）在公司界面 **任意月**可提交 |
| 借贷并发 | **有且仅有 1 笔** 未还清贷款同时进行 |
| 收购玩法 | **首版不做**（见 [02-economy.md](./02-economy.md)） |
