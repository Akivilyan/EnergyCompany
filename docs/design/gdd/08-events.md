# 事件系统

## 概述

事件系统承担**主要经营起伏**，风格参考《大理石时代》：有压力、有奖励、有市场与政策变化；通过**建设、研发、电价**等可理解维度制造波动，替代成就、竞争公司等复杂系统。

玩家通过**倒计时与摘要**提前感知即将到来的变化，在推月前调整建设、研发与现金流策略。

**与「关键节点反馈」的区分**（见 [01-core-loop.md](./01-core-loop.md)）：

| 类别 | 示例 | 反馈方式 |
|------|------|----------|
| **本系统·调度事件** | 政策补贴、油价上涨、设施建设冻结 | 事件面板 + 全屏弹窗（灾害/显著政策市场） |
| **其它关键节点** | 公司升级、科技点亮、供能 100% | 升级弹窗 / 界面内提示；**不**混入事件池 |

---

## 事件分类

首版按叙事与触发语境分三类（配置字段 `event_type`）：

| 类型 | 代码 | 典型题材 | 玩家预期 |
|------|------|----------|----------|
| **政策** | `policy` | 补贴、倡导某类能源、合规审查、建设/研发冻结 | 方向性变化，持续数月至整年 |
| **市场** | `market` | 油价、原材料、**电价**浮动 | 收入或运营成本波动 |
| **灾害** | `disaster` | 暴雪、洪水、断供 | **阶段性考试**；可压垮现金流 → 游戏失败 |

三类共用同一套 **效果类型** 与 **生命周期**；**灾害** 默认 **全屏弹窗**，且强度与失败风险最高（见「灾害：阶段性考试」）。

---

## 作用维度

首版效果按 **四条玩法线** 组织（对应玩家心智，而非仅 `effect_type` 枚举）：

### 建设类

| 方向 | 配置倾向 | 典型 `effect_type` |
|------|----------|-------------------|
| 建设费 **增 / 减** | 持续，可按能源类型 scoped | `build_cost_mult` |
| 工期 **增 / 减** | 持续或一次性 | `build_duration_delta`（月） |

挂载：**M1** 施工扣款与工期；与 [02-economy.md](./02-economy.md) 工期下限 **1 月** 叠加。

### 科技类

| 方向 | 配置倾向 | 典型 `effect_type` |
|------|----------|-------------------|
| 研发费 **增 / 减** | 开研时或持续 | `research_cost_mult` |
| 研发周期 **增 / 减** | 持续 | `research_duration_delta`（月）、`research_speed_mult` |

挂载：**M3** 科研项目推进；开研扣款在玩家点击时即时结算。

### 电价类

| 方向 | 配置倾向 | 典型 `effect_type` |
|------|----------|-------------------|
| 电费收入 **增 / 减** | 持续 | `income_mult` |

挂载：**M5** 月收入。文案层统一称「电价 / 电费」，不与运维成本混为一谈。

### 冻结类

| 方向 | 配置倾向 | 典型 `effect_type` |
|------|----------|-------------------|
| **禁止建设**某类设施 | 持续 | `freeze_build` + `target_scope`（能源类型或 tier） |
| **禁止开研**某科技节点或分页 | 持续 | `freeze_research` + `target_scope`（tech_id / 分页 / 整页） |

冻结期间：对应 **新建** 指令不可用（列表隐藏或灰显并提示原因）；**已在建 / 已在研** 项目 **不** 被暂停（除非另有 `build_duration_delta` / 研发减慢效果）。

### 补充（少量）

| 维度 | 说明 | 首版 |
|------|------|------|
| 一次性收支 | 补贴、罚款、灾后抢修 | `one_time_cash`；灾害考试常用 |
| 有效供能 | 区域出力折损 | `event_factor`（[04-energy-supply.md](./04-energy-supply.md)） |
| 运维成本 | 原材料等 | `operating_cost_mult`；market 类少量 |
| 社会价值 | 直接改 SV 公式 | **不做** |

**作用范围**（`target_scope`）：默认 **全局**；可收窄至能源类型、设施类型、科技分页或单个 `tech_id`。

## 并发与叠乘

| 规则 | 决策 |
|------|------|
| **同时 active 上限** | **≤ 3**；新排期实例若已满，推迟至有空槽的月份再 `active` |
| 同 `effect_type` + 同 `target_scope` | **叠乘**（如两个 `build_cost_mult` 0.8 与 0.9 → 0.72） |
| 强度与周期 | **因事件而异**；配置层用 `intensity_tier` + `duration_months` 区分，不做统一模板 |

首版 **不** 做玩家可选分支；全部为被动承受或享受。

---

## 触发与数值尺度

触发采用 **固定时间表 + 条件/权重随机** 组合（实现语法留 T22/T37）：

| 模式 | 用途 | 示例 |
|------|------|------|
| **固定时间表** | 教学节奏、章节型政策窗 | 「第 18 月」补贴储能系统研发或风光建设 |
| **权重随机** | 日常波动、市场类 | 按 `company_level` 从池子加权抽取 |
| **条件触发** | 阶段性考试 | 公司 **III 级且已解锁 ≥3 区** 时，灾害池权重上升 |

**按等级缩放（反「坑死玩家」）**：

- 每条事件配置 **基准值** + **`scale_by_company_level`**（I–V 查表或公式）。
- 负向效果上限：单次 `one_time_cash` 不超过该等级 **典型月净收入 × K**（K 待表，建议 2–4）；`build_cost_mult` / `income_mult` 偏离 1 的幅度随等级 **递减**（高等级玩家缓冲更大）。
- 随机池 **排除** 与当前状态组合后必然无解的条目（例：已 global 冻结建设时不再抽「建设费 +50%」同类惩罚）。
- 设计原则：**可以逼紧、可以亏损，但不应在玩家合理应对下仍几乎必败**；灾害是考试，不是掷骰子直接删档。

## 实例生命周期

```text
scheduled（已排期，未生效）
    │  玩家可见：倒计时 + 摘要
    ▼
active（生效中，剩余 duration_months）
    │  每月经 M11 扣减；效果参与 M1–M7 / M3；计入「≤3 并发」槽位
    ▼
expired（已结束）→ 移出活跃列表，可留历史摘要
```

**触发时机**：新实例进入 `active` 在 **M11**；默认 **当月起效**。

## 与月度结算的关系

事件在管道中的位置：**M11**（M10 之后，M12 之前）。

| 管道步骤 | 事件参与方式 |
|----------|--------------|
| M1 施工 | `build_cost_mult`、`build_duration_delta`、`freeze_build` |
| M3 研发 | 研发周期/费用修正、`freeze_research` |
| M4 供能 | `event_factor` |
| M5 收入 | `income_mult` |
| M6–M7 运营 | `operating_cost_mult` |
| M11 | 倒计时 −1；到期 → `expired`；新实例 → `active`（受 3 槽限制） |
| M12 | 灾害 / 显著政策市场 → **全屏弹窗** |

**一次性资金**（`one_time_cash`）：实例进入 `active` 当月，在 M5 之前入账。

## 灾害：阶段性考试

**定位**：灾害不是普通 debuff，而是 **阶段验收**——检验玩家是否储备了现金、减压科技与供能冗余。

| 属性 | 规则 |
|------|------|
| 反馈 | **一律全屏弹窗**（可与公司升级弹窗排队，见 01-core-loop） |
| 典型组合 | `one_time_cash`（负）+ `operating_cost_mult` 或 `event_factor` + 短周期 |
| 强度 | 高于同等级 policy/market；可 **单月或连续数月** 把 `funds` 压至 **< 0** |
| 失败 | 现金流被压制至无法维持经营 → **破产**（[02-economy.md](./02-economy.md)：连续 **2** 月末 `funds < 0`） |

**与 `eng_risk_reserve`**：仍仅减免负向 **`one_time_cash`** 的 15%；不减免持续收入削减或运维上升。

**玩家应对空间**：提前贷款、削减建设、取消研发换现金（全额退款）、依靠正向事件窗口——考试应 **可准备、可翻盘**，非纯随机秒杀。

---

## 固定灾害轴与随机事件（单局通关）

与 [11-replayability.md](./11-replayability.md) 对齐：**单局胜利 = 撑过固定灾害轴上最终一场且未破产**。

### 术语

| 术语 | 含义 |
|------|------|
| **固定灾害** | `campaign_disasters[]` 中的 **`event_type = disaster`**；在 **`trigger_month` 固定月份** 触发；全屏弹窗；带 **`exam_tier`**（考试档位 1～3） |
| **随机事件** | 事件池中的 **`policy` / `market`**（及其它权重条目），月份 **不固定**，可增益可减益 |
| **通关轴 / 战役** | 仅指上述 **固定灾害序列**（**4 场**，终局月 **86**，月表 **参差**），不含随机池 |

固定灾害月内 / 其它月份：随机事件池 **照常** 掷骰，可与固定灾害 **同月并存**（仍 **active ≤ 3**）。

### 规则

| 项 | 规则 |
|----|------|
| 配置 | `campaign_disasters[]`；**4 场**，`campaign_run_target_months = 86`；字段见 11-replayability |
| 触发 | **仅** `trigger_month`（**参差月表**，非等间距） |
| 预警 | **`warn_lead_months`** 随 **`exam_tier`**：**8 / 10 / 12** 月；**终局** **14** 月 |
| 类型 | 固定灾害均为 `disaster`；**一律全屏弹窗** |
| 强度 | `exam_tier` 1～3；简单难度降档 + 扣款 **75%**（见 11-replayability） |
| 备考 | 弹窗展示 **`exam_brief`**（建议等级/科技）；**未达标 → 加重惩罚**，**不** 单独 Game Over |
| 失败 | **仅** 连续 2 月末破产；灾害通过 **经济压力** 间接出局 |
| 最终场 | `is_final = true`；该场结算完成且 **未破产** → M14 **通关** |

固定灾害 **占用** active 槽位；与随机 policy/market **并存**（细则 T22）。

## 反馈与弹窗

| 情况 | 反馈 |
|------|------|
| 排期 / 进行中（一般） | 事件面板；城市 **悬浮按钮** 角标 |
| **灾害** | **全屏弹窗**（已决） |
| **政策 / 市场**，显著干预 | **全屏弹窗** |
| 同月 **公司升级** | **先升级**；事件弹窗排队或次月 |

「显著干预」启发式（可被 `show_fullscreen_popup` 覆盖）：`|one_time_cash|` 超比例、`mult` 偏离 ≥ 0.15、全局冻结等。

科技 **点亮** 不走事件池弹窗（[07-tech.md](./07-tech.md)）。

## 正负示例

### 正向

| 事件（示例） | 类型 | 效果 |
|--------------|------|------|
| 政策倡导风电和太阳能 | `policy` | 风/光 `build_cost_mult` ↓ |
| 全球天然气增产 | `market` | 火电 `operating_cost_mult` ↓ |
| 国家补贴储能系统 | `policy` | `storage_system_1～3` 研发 `cost_mult` ↓（或政策窗内风/光 `build_cost_mult` ↓，T37 定稿） |
| 产业联盟支持 | `policy` | 指定分页 `research_duration_delta` ↓ |
| 电价上调窗口 | `market` | `income_mult` ↑ |

### 负向

| 事件（示例） | 类型 | 效果 |
|--------------|------|------|
| 外部冲突推升油价 | `market` | 火电运维 ↑ |
| 合规审查 | `policy` | `freeze_research`（核电分页）若干月 |
| 暴雪 / 洪水 | `disaster` | 负向 `one_time_cash` + 区域 `event_factor` ↓；**弹窗** |
| 施工管制 | `policy` | `freeze_build`（某能源类型）+ 工期 ↑ |

## 首版本章边界

**包含**：四类效果线、≤3 并发、等级缩放、灾害考试与战役通关轴、UI 入口、弹窗规则。

**不包含**：完整事件池、触发 DSL、破产 UI、线框。

**不做**：可选分支事件、SV 直接修改、IAP 联动事件。

## 已决事项

| 议题 | 决策 |
|------|------|
| 效果线 | **建设**（费/期）、**科技**（费/期）、**电价**、**冻结**（设施/科技） |
| 并发上限 | 同时 active **≤ 3** |
| 触发 | **固定时间 + 随机/条件** 组合；数值 **按公司等级缩放**，避免必败局 |
| 叠乘 | 同 scope 同类型叠乘；强度与周期 **因事件而异** |
| 灾害 | **全屏弹窗**；阶段性考试；可压至负现金流并导向 **连续 2 月破产** |
| 单局通关 | **灾害战役** 最终场通过后 M14 判定（见 11-replayability） |
| 风险准备金 | 仅减负向 `one_time_cash` 15% |
| 主入口 | 城市悬浮按钮 → 事件面板 |
