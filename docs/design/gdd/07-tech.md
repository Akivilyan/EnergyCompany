# 科技研发

## 概述

科技树与 **公司等级 I–V** 强绑定：**城镇中心·N 级 = 公司 N 级**（M10 同步）。首版约 **35** 个可研节点 + 开局 **已点亮** 的四线 ·I。

- **界面**：参考 **《帝国时代 2》**——按 **领域分页** + **等级列** 平铺；**不** 用大理石式交叉树（[META.md §10](../META.md#10-设计参考长期)）。
- **II 级起** 才开放 **`screen_tech_tree`**；I 级仅享受开局已点亮的 ·I 效果。
- **风 / 光 / 火 / 水** 各 **1～V 级**，与公司等级 **一一解锁**；风光水 **·III～V** 另受 **储能系统·I～III** 卡住。
- **储能系统·I～III**（`storage_1～3`，III～V 解锁）：**·I 点亮** 启用风/光/水 **`storage_mult = 2`**（拉平波动）；**·II / ·III** 仅解锁更高发电 tier（见下）。
- **核电** 独立三线（III～V）；**电网** 区域 III、主干 IV、特高压 V；**超级水电** V（无储能配套）。

---

## 术语：解锁 vs 点亮

| 术语 | 含义 |
|------|------|
| **解锁** | 公司等级 / 前置节点满足 → 可 **付费开研**（`unlocked`） |
| **点亮** | 研发完成（`lit`）→ 效果生效；设施/电网 **自动同步**（[05-map-and-slots.md](./05-map-and-slots.md)） |

```text
locked → unlocked → researching → lit
```

**公司升档时**：该档对应的发电 ·N、**储能系统** ·N（若适用）等节点 **批量解锁**（仍为 `unlocked`，需玩家开研才 `lit`）。  
**例外**：开局风/光/火/水 **·I 开局即 `lit`**。

## 系统开放与研发规则

### 科技界面开放

| 公司等级 | 科技树界面 |
|----------|------------|
| **I** | **不开放** `screen_tech_tree`（无研发入口）；风/光/火/水 **·I 已点亮** |
| **II～V** | 开放；顶栏显示 **城镇中心·II…V** |

### 付费、取消、管道

| 规则 | 说明 |
|------|------|
| 付费 | 开研时 **一次性** 扣 `research_cost` |
| 进度 | **M3** 按月；完成当月 **点亮** |
| 取消 | **全额退款** |
| 并行 | **单队列**：II 级起 **同时仅 1 项** 在研（`researching`）；无第二槽 |

### 公司等级与节点解锁（总原则）

| 公司等级 | 发电线（风/光/火/水） | 储能系统 | 其它 |
|----------|----------------------|------|------|
| **I** | ·I **已点亮**（开局） | — | 科技界面关闭 |
| **II** | ·II **解锁** | — | 开放科技树 |
| **III** | ·III **解锁**；须 **`storage_1` 已 lit** 才可研 ·III | **储能系统·I**（`storage_1`）**解锁** | 区域电网、核电·I **解锁** |
| **IV** | ·IV **解锁**；须 **`storage_2` 已 lit** | **储能系统·II**（`storage_2`）**解锁** | 主干电网、核电·II；清洁煤电、无害化核废料 |
| **V** | ·V **解锁**；须 **`storage_3` 已 lit** | **储能系统·III**（`storage_3`）**解锁** | 特高压、核电·III、超级水电 |

**储能系统·I～III 与风光水 ·III～V**（`tech_id` 仍用 `storage_1～3`）：

```text
点亮 storage_1（储能系统·I）→ storage_mult = 2，且可研/点亮 wind_3 / solar_3 / hydro_3
点亮 storage_2（储能系统·II）→ 可研/点亮 ·IV
点亮 storage_3（储能系统·III）→ 可研/点亮 ·V
```

**火电 ·I～V**、**火电 ECO**：**不** 受储能系统闸门；仅公司等级 + 各档研发。

## 界面结构（等级轨 + 分页）

```text
screen_tech_tree（II 级起可见）
├── 顶栏：城镇中心·{当前等级}  在研 0/1 或 1/1
├── 分页：风电 | 光伏 | 火电 | 水电 | 核电 | 电网 | 经营
└── 主区（每页）：
      列标题：  I    II   III   IV    V     ← 公司等级轨
      发电·N： [●] [○] [○] [○] [○]   ●=lit ○=unlocked/locked
      储能系统：    —   —  [I] [II][III]   （新能源页 / 风光水页共享一行；仅 III～V 列有节点）
      减压节点：  小图标行，标「减压」色
```

| UI 原则 | 说明 |
|---------|------|
| **等级轨** | 玩家一眼看到「升到 IV 还能点什么」 |
| **强度节点** | 发电 ·N、核电、电网主干 — 大图标 |
| **减压节点** | 经营页 + 少量跨页 — 小图标、绿色/蓝色边框 |
| **不可研** | 灰显 + 文案：「需要公司·IV」「需要先完成储能系统·II」 |

## 发电四线（风 / 光 / 火 / 水）·I～V

四线 **结构相同**：5 个 tier 节点，`tech_id` = `{wind|solar|thermal|hydro}_{1..5}`，显示名 **风电·I** … **水电·V**。

| 节点 | 公司等级 | 点亮效果 |
|------|----------|----------|
| `*_1` | I | 开局 **已 lit**；`facility_build_tier_max` ≥ 1 |
| `*_2` | II | tier ≥ 2；已建同线设施 **自动同步** |
| `*_3` | III | tier ≥ 3；须 `storage_1`（**储能系统·I**）**lit** 才可研 |
| `*_4` | IV | tier ≥ 4；须 `storage_2`（**储能系统·II**）**lit** |
| `*_5` | V | tier ≥ 5；须 `storage_3`（**储能系统·III**）**lit** |

**同线有效 tier** = 该线已 **点亮** 节点中的 **最高 N**（建造列表只显示该 tier，[05-map-and-slots.md](./05-map-and-slots.md)）。

### 火电 ·IV 环保（无绿色闸门）

| `tech_id` | 显示名 | 公司等级 | 点亮效果 |
|-----------|--------|----------|----------|
| `eco_thermal` | 清洁煤电改造 | **IV** | 全部已完工火电 **即时** `is_eco = true`（M3 完成拍同步） |

**无** 独立「绿色路线图」节点；IV 研完即 ECO。

## 储能系统·I～III（新能源页 / 风光水页共享一行）

**2026-05 合并**：旧稿拆成 **`storage_system`（出力 ×2）** + **`storage_1`（卡 ·III）** 两个节点，玩家与策划易混淆。现 **合并为一条三级线**：显示名 **储能系统·I / ·II / ·III**，`tech_id` 仍为 `storage_1～3`（少维护改表）。

**非设施**：更早草案曾有「初级/中级/高级储能设备」等 **可部署设施**；为简化已 **取消**，储能效果 **仅** 在本节科技树体现（见 [`tech-tree-design.md`](../../tech-tree-design.md) §1.1）。

| `tech_id` | 显示名 | 公司等级 | 点亮效果 |
|-----------|--------|----------|----------|
| `storage_1` | **储能系统·I** | **III** 解锁 | ① 风光水 **`storage_mult = 2`**（拉平波动，见下） ② 允许研发/点亮风/光/水 **·III** |
| `storage_2` | **储能系统·II** | **IV** 解锁 | 允许研发/点亮风/光/水 **·IV**（**不** 再叠 `storage_mult`） |
| `storage_3` | **储能系统·III** | **V** 解锁 | 允许研发/点亮风/光/水 **·V** |

### 储能系统·I 的供能效果（`storage_1` 点亮后）

对 **风电、光伏、常规水电**（**不含** 超级水电）：

| 乘区 | 未点亮 `storage_1` | 已点亮 `storage_1` |
|------|-------------------|---------------------|
| `storage_mult` | **1** | **2**（在 **标称 × 区域乘区** 之后叠乘） |

**区域乘区** `region_mult` 仍为 **1 或 2**，与储能 **独立**。公式见 [04-energy-supply.md](./04-energy-supply.md)。

**超级水电**：不吃储能；**·II / ·III** 仅作 **tier 闸门**，不改变 `storage_mult`。

## 经营与减压（零散科技）

**定位**：在公司升档、发电加码的同时，给 **减负**（**不含施工工期 −1**；工期减免专属于 **工程总监** 与 **激励广告**，以体现钞能力价值）。首版 **6** 个 `eng_*`，均在 **经营** 分页（II 级起随等级解锁）。

**点亮预算**：非科技方针 **`doctrine_lit_budget = 15`**，与主线节点 **同一池**；`eng_*` 与发电/电网/储能等 **自由竞争** 点数（见 [11-replayability.md](./11-replayability.md)）。`tech` 方针无上限。

| `tech_id` | 显示名 | 等级 | 类型 | 点亮效果（定性） |
|-----------|--------|------|------|------------------|
| `eng_bulk_procure` | 集中采购 | **II** | 减压 | 建设费 **−8%** |
| `eng_ops_contract` | 运维外包 | **III** | 减压 | 月运维 **−10%** |
| `eng_grid_dispatch` | 智能调度 | **III** | 强度辅助 | 区域线损 **−10%**（固定 MW 乘 0.9，[06-grid.md](./06-grid.md) 乘数） |
| `eng_cashflow` | 现金流管理 | **IV** | 减压 | 贷款 **+1 档**（见 [09-year-end-and-monetization.md](./09-year-end-and-monetization.md)） |
| `eng_risk_reserve` | 风险准备金 | **IV** | 减压 | 负向事件资金损失 **−15%**（[08-events.md](./08-events.md) 挂钩，T10） |
| `eng_green_pr` | 绿色品牌 | **V** | 强度辅助 | 全环保城 `city_base` 社会价值 **+5%**（×1.05）；风光局常见终局选择之一 |

**强度 vs 减压节奏**：

| 等级 | 玩家压力来源 | 科技树对策 |
|------|--------------|------------|
| II | 扩区、单研发队列、3 在建上限 | 集采减建设费 |
| III | 储能系统·I、区域网、核电 | 运维外包、调度减线损 |
| IV | 主干线损、ECO 成本、多城 | 现金流、事件减损 |
| V | 全图、特高压、超水电 | 绿色品牌 |

## 经营方针与点亮预算

单局 **`doctrine_id`** 决定开局 modifier 与 lit 规则（详见 [11-replayability.md](./11-replayability.md)）。

### 非科技方针：`doctrine_lit_budget = 15`

| 规则 | 说明 |
|------|------|
| 计数 | 每 lit 一个节点（含 `eng_*`）→ 预算 **−1** |
| 不计入 | 全局开局 ·I；风光额外 **`storage_1`（储能系统·I）** 已 lit |
| 自由分配 | **不区分** 主线 / 经营；玩家在 15 点内自行取舍 |
| UI | 「本局剩余点亮：N / 15」 |

### 科技方针 `tech`

**无** lit 预算上限；可点亮全部可研节点。

### 异线 tier 硬顶

非 `tech` 方针下，**非本线** 发电节点 **不可研 ·II 及以上**（·I 保持开局 lit）。**例外**：`hydro` 方针下 **`nuclear_*` 视为本线**（可研 ·II～III）。细则见 [11-replayability.md](./11-replayability.md)。

电网 `grid_*`、`super_hydro`、本线 ·II～V 不受异线硬顶。

### 方针开局点亮（摘要）

| 方针 | 额外开局 `lit` |
|------|----------------|
| `renewable` | **`storage_1`（储能系统·I）** 已 lit（**不**送 `storage_2～3`） |
| `thermal` | `eco_thermal`、`eco_nuclear` |
| `hydro` / `tech` | —（仅 modifier 表） |
