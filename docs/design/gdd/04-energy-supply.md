# 供能与能源类型

## 概述

本章定义 **按城市** 的供能核心指标、**有效供能** 的修正链、**首版五种能源类型** 的特殊规则，以及与社会价值 **全环保判定** 的衔接。

- **唯一核心指标**：**供能满足率**（不做需求梯度、不拆分工业/民用等类别）。
- **计算节拍**：每月 **M4** 在玩家点击 `下一月` 后重算（见 [核心循环与时间](./01-core-loop.md)）。
- **粒度**：建设、供能条、满足率均以 **城市** 为单位；**都** 视为一座城；**区** 内每座可操作城市各算一套（见 [社会价值与公司等级](./03-social-value.md)）。

---

## 供能满足率

### 定义

```text
satisfaction_rate_city = clamp( effective_supply_city / demand_city , 0 , 1 )
```

| 符号 | 含义 |
|------|------|
| `demand_city` | 该城 **当前总需求**（MW 或抽象单位，与设施出力同量纲） |
| `effective_supply_city` | 经下文修正后的 **可用供能** |
| `clamp(..., 0, 1)` | 供能超过需求时满足率 **封顶为 100%** |

**首版不做**多档需求类型；前台 **不展示** 需求梯度或分类列表。

### 前台展示（城市界面）

仅展示三项（可与 `200/300` 式进度条并列）：

| 展示项 | 说明 |
|--------|------|
| 当前总需求 | `demand_city` |
| 当前有效供能 | `effective_supply_city` |
| 供能满足率 | 百分比或 0–1；**100%** 时用界面内提示，**不用**全屏弹窗（见 [01-core-loop.md](./01-core-loop.md)） |

区域/大地图上的供能概况为 **汇总或摘要**，规则以城市为准，UI 细则见后续 Feature/UI 任务。

### 与社会价值的关系

| 输入 | 作用 |
|------|------|
| `satisfaction_rate_city` | 满足率越高，该城社会价值 **按比例** 越高 |
| `city_fully_eco_supply` | 该城 **本市设施** 均为环保 → 社会价值 **100%** 潜力；本市有非环保机组 → **上限 80%**（受入外电不追溯） |

**勿混淆**：城市供能条（如 `200/300`）≠ 顶栏社会价值。供能 100% 但含一台未升级火电/核电 → 社会价值仍只按 **80%** 潜力结算。

## 有效供能

**有效供能** 不是设施 **产能量** 简单加总，而是当月可用于满足该城需求的 **修正后出力**。

### 设施属性与展示（产能）

每座设施在配置表中有稳定字段（实现名见 `data/`，T37）；**玩家文案统一用「产能量」**，不用「铭牌」「×2」等策划黑话。

| 字段（data） | 玩家可见名 | 说明 |
|--------------|------------|------|
| `facility_type` + `tier` | **设施名·lv** | 例：风电·2级、火电·4级 |
| `output_capacity_mw` | **产能量（标称）** | 表内为 **已计入现实波动后的平均出力**（非峰值）；升级 **改表中的值** |
| `monthly_operating_cost` | **运行费用** | x/月 |
| `build_cost_total` / 工期 | **建设费用**、工期 | 仅 **建造列表** 与确认框展示 |

| 界面 | 展示 |
|------|------|
| **建造列表**（点空位） | 每项至少：**设施名-lv**、**建设费用**、**产能量**、**运行费用**（详见 [05-map-and-slots.md](./05-map-and-slots.md)） |
| **城内设施**（三国志12 位图） | 常显：状态图标（在建/运行/升级中等）；**点按** 设施 → 详情（例：风电·2级，产能量：100MW，运行费用：0/月） |
| **升级后** | 产能量、运行费用等 **以升级目标行的配置为准**（可升可不变，由表决定） |

### 分层公式（设施 → 城市 → 电网）

**设施供能**（不算电网；仅已完工机组）：

```text
facility_supply_i = nominal_output_i × region_mult_i × storage_mult_i × event_factor_i
```

| 因子 | 取值 | 适用 |
|------|------|------|
| `nominal_output` | 表字段 `output_capacity_mw`（**标称产能量**） | 全部类型 |
| `region_mult` | **1** 或 **2** | 风电、光伏、**常规水电**（一般区 / 富资源区） |
| `storage_mult` | **1** 或 **2** | 同上；**`storage_system_1`（储能系统·I）点亮** 后为 **2**（拉平波动） |
| `region_mult` / `storage_mult` | 恒 **1** | 火电、核电、**超级水电** |
| `event_factor` | 事件表 | 全部 |
| `doctrine_hydro_mult` | 仅 **水电方针** | 常规水电、超级水电（见 [11-replayability.md](./11-replayability.md)） |

**风光水简化模型**（现实中有出力波动，本游戏不做逐时模拟）：

- 默认可变电源 **带波动**；配置中的 **标称产能量 = 波动折算后的平均值**。
- **富资源区** ×2、**储能系统·I 点亮** 再 ×2；两个乘区 **独立叠乘**，均为 **1 或 2**。

```text
region_mult   = 1   // 风/光/水：一般区域
              = 2   // 风/光/水：丰富区域
storage_mult  = 1   // 未点亮 storage_system_1（储能系统·I）
              = 2   // 已点亮 storage_system_1（拉平波动 → 在原有平均出力上 ×2）

// 例：标称 100，富资源区，已储能
facility_supply = 100 × 2 × 2 = 400
```

| 因子 | 作用层级 |
|------|----------|
| `nominal_output` | 设施表 / 科技同步后的 tier 行 |
| `region_mult` / `storage_mult` | 仅风光水常规机组；见下节 |
| `event_factor` | 事件临时修正 |
| **电网** | **不在设施层**；在「并网岛」层一次结算（见 [06-grid.md](./06-grid.md)） |

**城市本地发电**：

```text
local_supply_city = Σ facility_supply_i   // 本市所有已完工机组
```

**城市有效供能**（供满足率用）：

```text
net_import_city = 电网调剂结果（可正可负；见 06-grid「并网岛」算法）
effective_supply_city = local_supply_city + net_import_city
satisfaction_rate_city = clamp( effective_supply_city / demand_city , 0 , 1 )
```

| 展示项 | 含义 |
|--------|------|
| `local_supply` | 本市机组合计 |
| `net_import` | **受入 − 外送** 的净值；正=净受入，负=净外送 |
| `effective_supply` | 本地 + 净值；用于 `200/300` 式供能条 |

电网采用 **并网岛 + 固定线损 + 按需求比例分配**（[06-grid.md](./06-grid.md)，**已确认**）；未联网城市仅本地发电。

**环保判定不追溯电网**：只查 **本市机组** `is_eco`；**外电输入一律视同环保**；本市外送不使他城受罚。

### 影响因素清单

| 因素 | 说明 |
|------|------|
| 产能量 | `facility_config.output_capacity_mw`（旧表字段 `nominal_output_mw` 同义，T37 统一命名） |
| 是否完工 | 在建不计入；**完工次月** 起计入（与 [02-economy.md](./02-economy.md) 一致） |
| 地区资源禀赋 | 风能标签、日照档位、`fossil_energy` 等（后者主要影响 **运行费用**，见经济章） |
| 科技驱动同步 | 发电线 ·II～V、环保节点 **点亮** 当月 → **自动** 更新 tier / `is_eco`（见 [07-tech.md](./07-tech.md)、[05-map-and-slots.md](./05-map-and-slots.md)） |
| 环保身份 `is_eco` | 仅 **本市设施** 参与「全环保」判定；电网受入/外送 **不追溯** |
| 电网 | 在 **并网岛** 层扣固定线损并分配 `net_import`；设施层不算电网（[06-grid.md](./06-grid.md)） |
| 事件 | 可临时修正出力、成本或收入（[08-events.md](./08-events.md)） |

具体并网算法在 **T16** 与 [06-grid.md](./06-grid.md) 定稿；本章只约束 **分层语义**（设施 / 城市 / 电网）。

### 总需求 `demand_city`

| 规则 | 说明 |
|------|------|
| 来源 | 城市/节点数值表字段 **`base_demand_mw`**（`data/`，T37）；建议按城市类型范围选值：中心 1000–1400、常规 400–700、农村 70–140、边陲 40–90、**都 1600–2200** |
| 首版 | **仅静态配置**；版本更新时改表即可调平衡，**不做**玩家侧需求管理玩法 |
| 事件/科技 | 首版 **不** 通过事件或科技动态改需求；若后续版本开放，须单独立项 |

## 环保供能判定（社会价值用）

社会价值 **不再** 使用「清洁供能占比 × 20%」双轨公式，改为 **全城是否全环保** 的 **一票否决式上限**（详见 [03-social-value.md](./03-social-value.md)）。

### 判定字段

```text
city_fully_eco_supply = true
    当且仅当：本市范围内、已完工且纳入供能结算的每一座设施 is_eco == true

// 不计入：import_supply_city（电网受入）
// 不连带：本市外送对他城无环保判定影响
```

| 范围 | 环保判定 |
|------|----------|
| 本市风电、光伏、水电、火电、核电等 | 须全部 `is_eco == true` 才 **全环保** |
| 经电网 **受入** 的电力 | **视同环保**；不计入、不追溯、不拖后腿 |
| 本市 **外送** 至他城 | **不判定**、不使他城受罚 |

| 输出 | 说明 |
|------|------|
| `city_fully_eco_supply` | M4 与满足率一并算出，供 M9 使用 |
| `eco_cap_factor` | `1.0`（全环保）或 `0.8`（否则）；实现可缓存 |

### 环保身份 `is_eco`（按设施）

| 能源类型 | 默认 `is_eco` | 变为环保的条件 |
|----------|---------------|----------------|
| 风电 | **是** | — |
| 太阳能 | **是** | — |
| 水电 | **是** | — |
| 火电 | **否** | **`eco_thermal`** 研发完成 → 已完工火电 **自动** 环保化 |
| 核电 | **否** | **`eco_nuclear`** 研发完成 → 已完工核电 **自动** 环保化 |

**设计意图**：

- 本市 **仅** 风/光/水，或火/核均已环保升级 → **全环保** → 社会价值可按 **`city_base` 的 100%** 潜力（再乘满足率）。
- 本市存在 **任意一台** 未升级火电/核电（哪怕闲置、哪怕满足率主要靠外电）→ **非全环保** → 社会价值 **最多** `city_base × 80%`（再乘满足率）。
- 本市无机组、100% 靠外电满供 → **全环保**（外电视同环保 + 本市无设施）。
- 后期鼓励：**联网受入** 超级水电/风光外送，同时 **拆除或不再新建** 本市高运维火电/核电（见下节「后期供能尺度」）。

环保升级 **默认不提高产能量**（除非表中为该升级单独配置了更高 `output_capacity_mw`）；主要改变 `is_eco` 与 **运行费用**（待表）。

### 示例

| 城市供能结构 | 满足率 | `city_fully_eco_supply` | 满供时社会价值潜力 |
|--------------|--------|-------------------------|-------------------|
| 仅风电，风能一般 | 100% | true | **100%** `city_base` |
| 100% 满足率，本市 1 台未升级火电（可闲置） | 100% | **false** | **80%** `city_base` |
| 100% 满足率，本市仅环保升级火电 | 100% | true | **100%** `city_base` |
| 100% 满足率，本市无机组、全靠外电（含邻市煤电） | 100% | **true**（外电视同环保） | **100%** `city_base` |
| 100% 满足率，本市有未升级核电 + 大量清洁外电 | 100% | **false**（本市有机组） | **80%** `city_base` |

## 首版能源类型

首版突出五类：**火电、水电、风电、太阳能、核电**。

每类在数值表统一暴露（实现字段名见 `balance-data-structure.md`）：

| 参数 | 说明 |
|------|------|
| 建设费用 / 工期 | 分期扣款见 [02-economy.md](./02-economy.md) |
| 月运营成本 | 受地区 `operation_cost_modifier`、`fossil_energy` 等影响 |
| 有效供能能力 | 产能量 × 本章资源修正 |

**不在首版 GDD 展开**：机组级热效率曲线、燃料库存、弃风弃光详细仿真。

### 火电 `thermal`

| 项 | 规则 |
|----|------|
| 定位 | 前期易上量、运维可调；**默认非环保**（`is_eco = false`） |
| 环保路线 | **`eco_thermal`**（**清洁煤电改造**）研发完成 → **已完工** 火电机组 **自动** `is_eco = true`（无手动升级） |
| 运维 | 环保升级后 **月运营成本上升**（倍率待表）；`fossil_energy` 地区标签仍只减运维，不改 `is_eco` |

### 水电 `hydro`

| 项 | 规则 |
|----|------|
| 环保 | **是**（`is_eco = true`） |
| 选址 | 仅 **近江河** 城市可建（地图章 T07 定槽位） |
| 常规 vs 超级 | **超级水电** 需 V 级科技；全图 **2** 座；单座策划尺度 ≈ **2 省** 体量联网供电、两座 ≈ **4 省**（各省 6–8 城不等；MW 待精算，见下节） |

### 风电 / 光伏 / 常规水电（可变电源）

三类共用 **标称 × 区域乘区 × 储能乘区**（见上节公式）。

| 标签（风/光示例） | `region_mult` |
|-------------------|---------------|
| `wind_normal` / `solar_normal`（一般） | **1** |
| `wind_rich` / `solar_rich`（丰富） | **2** |
| 常规水电 | 由城市/省级水资源标签映射为 **1 或 2**（`data/`，T37） |

| **`storage_system_1`（储能系统·I）** | `storage_mult` |
|------------------------------|----------------|
| 未点亮 | **1** |
| 已点亮 | **2**（拉平波动；在 **当前** 标称×区域 结果上再 ×2） |

建设界面须 **明示** 资源档位（一般/丰富）；**储能系统·I** 点亮后 UI 可提示「储能已启用：出力 ×2」。

**超级水电**：**不** 走 `region_mult` / `storage_mult`；标称即稳定出力，**无** 波动、**不** 吃储能（[07-tech.md](./07-tech.md)）。

### 水电方针额外乘区

仅当本局 `doctrine_id = hydro`（见 [11-replayability.md](./11-replayability.md)）：

```text
// 常规水电（临水城市）
facility_supply = nominal × region_mult × storage_mult × doctrine_hydro_mult × event_factor

// 超级水电
facility_supply = nominal × doctrine_super_hydro_mult × event_factor
```

| 字段 | 说明 |
|------|------|
| `doctrine_hydro_mult` | 整数比 `mult_num / mult_den`；随方针局外等级略升 |
| `doctrine_super_hydro_mult` | 超级水电 **单独** 配置，可与常规不同 |

**不** 改变临水选址规则；优势仅在供能数值。

**储能系统·II / ·III**（`storage_system_2～3`）：仅 **解锁** 风光水 ·IV / ·V；**不** 改变 `storage_mult`（×2 仅来自 **·I**）。

### 火电 / 核电

`region_mult = storage_mult = 1`；供能 = 标称 × `event_factor`（另见 ECO、运维规则）。

### 科技驱动机组同步

与 [07-tech.md](./07-tech.md)、[05-map-and-slots.md](./05-map-and-slots.md) 一致：

| 触发 | 对象 | 写入 |
|------|------|------|
| `wind_N` / `solar_N` / `thermal_N` / `hydro_N` **点亮** | 该线已完工设施 | 升至对应 **tier N** 配置行 |
| `eco_thermal` **点亮**（IV） | 已完工火电 | **即时** `is_eco = true` |
| `eco_nuclear`（无害化核废料）**点亮**（IV） | 已完工核电 | **即时** `is_eco = true` |
| **`storage_system_1` 点亮** | — | 全局 `storage_system_tier_1_lit`（实现可沿用 `storage_system_1_lit`）；M4 起重算风光水出力 |

**无** 手动 [升级]、**无** 升级费/工期。tier 升档改 **标称** 表值；**区域/储能乘区** 仅取 1 或 2，**禁止** 在代码里写其它倍率。

### 核电 `nuclear`

| 项 | 规则 |
|----|------|
| 环保 | **默认否**；**无害化核废料**（IV）点亮 → 已完工核电 **自动** 环保化 |
| 解锁 | 公司 **III 级** + `nuclear_1` 点亮（[07-tech.md](./07-tech.md)）；选址仍限中心城/都 |
| 选址 | **省内中心大城市** 或 **都**（那座特大城本身） |
| 出力 | 按产能量与电网规则计，无风/光式地区折减 |

## 后期供能尺度与玩家取舍（策划意图）

整体架构下，**火电、核电单城供能上限有限**，无法单靠火/核铺满全图；**全图绿色供能**依赖 **储能系统·I～III**、发电 **·V**、**ECO 改造**、**超级水电** 与 **电网调配**。

| 阶段 | 玩家路径 |
|------|----------|
| 前期 | 火电等易上量；本市若留未升级火/核 → 社会价值 **80%** 上限 |
| 中期 | 区域风光、常规水电；开始 **拉电网** |
| 后期 | 全图 **2** 座超级水电（各约 **2 省** 联网体量）+ 主干/区域网；受电城可 **少建或不建** 本地火/核 |

**地图与尺度**：每省 **6–8** 个可经营节点、**逐省不同**（见 [03-social-value.md](./03-social-value.md)）。超级水电「能供几个省」取决于各省城数与需求配置，GDD **不写死** 固定城数。

**火/核电运维**：维持成本 **显著偏高**；盈亏与取舍留给玩家在数值表里 **自己算账**（养不起则拆本地、吃外电）。

**电网玩法**：外电只抬 **满足率**；外电 **视同环保** + 仅判本市 → 鼓励「清洁基地外送 + 用电城拆掉本地煤电」。链接与损耗见 [06-grid.md](./06-grid.md)。

| 阶段 | 内容 |
|------|------|
| **当前（GDD）** | 只写 **定性思路**（谁强谁弱、量级关系、玩家取舍），便于架构定型 |
| **架构 locked 后** | 再 **精算** MW、造价、运维、门槛、超级水电出力等（`data/`、T37–T39）；可玩性依赖合理数值，不单靠公式 |

## 已决事项

| 议题 | 决策 |
|------|------|
| 核心指标 | 仅 **供能满足率**，无需求梯度 |
| 满足率封顶 | 供能 > 需求时按 **100%** |
| 计算粒度 | **按城市** |
| 能源类型 | 火电、水电、风电、太阳能、核电 |
| 风/光地区系数 | 一般 **100%**；丰富 **200%**（光伏与风电同逻辑） |
| 发电 tier | 风/光/火/水 **·I～V** 与公司等级绑定；**点亮** 后自动同步 |
| 储能系统·I～III | **·I 点亮** → `storage_mult=2`；**·II/·III** 卡 ·IV/·V |
| 火/核环保 | IV **清洁煤电** / **无害化核废料** 点亮 → **即时** ECO |
| 天然环保 | 风、光、水 **始终** `is_eco` |
| 社会价值衔接 | **全环保** → 100% 潜力；否则 **上限 80%**（与满足率相乘） |
| 城市需求 | **仅静态配置表** `base_demand_mw` |
| 跨城供电 | 受入计入 **满足率**；外电 **视同环保**；环保仅判 **本市机组** |
| 省内城数 | 每省 **6–8** 节点，逐省配置（非固定模板） |
| 后期尺度 | 超级水电 ≈ **2 省/座**（定性）；数值 **架构后精算** |
| 100% 供能反馈 | 界面内提示，不弹全屏 |
