# 供能与能源类型

## 概述

本章定义 **按城市** 的供能核心指标、**有效供能** 的修正链、**首版五种能源类型** 的特殊规则，以及与社会价值 **全环保判定** 的衔接。

- **唯一核心指标**：**供能满足率**（不做需求梯度、不拆分工业/民用等类别）。
- **计算节拍**：每月 **M4** 在玩家点击 `下一月` 后重算（见 [核心循环与时间](./01-core-loop.md)）。
- **粒度**：建设、供能条、满足率均以 **城市** 为单位；**都** 视为一座城；**区** 内每座可操作城市各算一套（见 [社会价值与公司等级](./03-social-value.md)）。

---

## 供能满足率

### 定义

```text
satisfaction_rate_city = clamp( effective_supply_city / demand_city , 0 , 1 )
```

| 符号 | 含义 |
|------|------|
| `demand_city` | 该城 **当前总需求**（MW 或抽象单位，与设施出力同量纲） |
| `effective_supply_city` | 经下文修正后的 **可用供能** |
| `clamp(..., 0, 1)` | 供能超过需求时满足率 **封顶为 100%** |

**首版不做**多档需求类型；前台 **不展示** 需求梯度或分类列表。

### 前台展示（城市界面）

仅展示三项（可与 `200/300` 式进度条并列）：

| 展示项 | 说明 |
|--------|------|
| 当前总需求 | `demand_city` |
| 当前有效供能 | `effective_supply_city` |
| 供能满足率 | 百分比或 0–1；**100%** 时用界面内提示，**不用**全屏弹窗（见 [01-core-loop.md](./01-core-loop.md)） |

区域/大地图上的供能概况为 **汇总或摘要**，规则以城市为准，UI 细则见后续 Feature/UI 任务。

### 与社会价值的关系

| 输入 | 作用 |
|------|------|
| `satisfaction_rate_city` | 满足率越高，该城社会价值 **按比例** 越高 |
| `city_fully_eco_supply` | 该城 **本市设施** 均为环保 → 社会价值 **100%** 潜力；本市有非环保机组 → **上限 80%**（受入外电不追溯） |

**勿混淆**：城市供能条（如 `200/300`）≠ 顶栏社会价值。供能 100% 但含一台未升级火电/核电 → 社会价值仍只按 **80%** 潜力结算。

## 有效供能

**有效供能** 不是设施铭牌加总，而是当月可用于满足该城需求的 **修正后出力**。

### 计算思路（单城）

```text
对每座已完工、可发电的设施 i（本市）：
    unit_i = nominal_output_i              // 含 wind_max / solar_max 升级后的铭牌（见下文）
           × resource_factor_i            // 风/光地区标签（一般 100%、丰富 200%）
           × grid_factor_i                // 并网、对外输送时的链路损耗（见 06-grid）
           × event_factor_i               // 事件倍率（若有）

import_supply_city = Σ 经区域/主干电网送入本城的电力_j
                     // 扣链路固定损耗后计入；模拟「外电支援本市」

gross_supply_city = Σ unit_i + import_supply_city

effective_supply_city = apply_city_losses( gross_supply_city )   // 城市级汇总损耗（若有）
```

**跨城输入**：经电网送入的电力 **计入受电城市的 `effective_supply_city`**，只影响 **供能满足率**。电网用于调配余缺；固定损耗等抽象见 [06-grid.md](./06-grid.md)。

**环保判定不追溯电网**：只查 **本市机组** `is_eco`；**外电输入一律视同环保**（不参与处罚、不追溯来源）；本市 **外送** 不使他城受罚。避免单城非环保拖垮全网。

### 影响因素清单

| 因素 | 说明 |
|------|------|
| 设施额定出力 | `facility_config.nominal_output_mw` |
| 是否完工 | 在建不计入；**完工次月** 起计入（与 [02-economy.md](./02-economy.md) 一致） |
| 地区资源禀赋 | 风能标签、日照档位、`fossil_energy` 等（后者主要影响 **运营成本**，见经济章） |
| 机组升级档位 | `wind_max` / `solar_max` → 风/光铭牌 ×2；环保火电/核电科技 → 火/核机组标为 **环保** |
| 环保身份 `is_eco` | 仅 **本市设施** 参与「全环保」判定；电网受入/外送 **不追溯** |
| 电网接入与损耗 | 本市出力可经网外送；**外电输入计入受电城有效供能**；链路固定损耗（[06-grid.md](./06-grid.md)） |
| 事件 | 可临时修正出力、成本或收入（[08-events.md](./08-events.md)） |

具体加权顺序与 **`grid_factor`** 在 Feature **T16** 与电网章定稿；本章只约束 **输入输出语义**。

### 总需求 `demand_city`

| 规则 | 说明 |
|------|------|
| 来源 | 城市/节点数值表字段 **`base_demand_mw`**（`data/`，T37） |
| 首版 | **仅静态配置**；版本更新时改表即可调平衡，**不做**玩家侧需求管理玩法 |
| 事件/科技 | 首版 **不** 通过事件或科技动态改需求；若后续版本开放，须单独立项 |

## 环保供能判定（社会价值用）

社会价值 **不再** 使用「清洁供能占比 × 20%」双轨公式，改为 **全城是否全环保** 的 **一票否决式上限**（详见 [03-social-value.md](./03-social-value.md)）。

### 判定字段

```text
city_fully_eco_supply = true
    当且仅当：本市范围内、已完工且纳入供能结算的每一座设施 is_eco == true

// 不计入：import_supply_city（电网受入）
// 不连带：本市外送对他城无环保判定影响
```

| 范围 | 环保判定 |
|------|----------|
| 本市风电、光伏、水电、火电、核电等 | 须全部 `is_eco == true` 才 **全环保** |
| 经电网 **受入** 的电力 | **视同环保**；不计入、不追溯、不拖后腿 |
| 本市 **外送** 至他城 | **不判定**、不使他城受罚 |

| 输出 | 说明 |
|------|------|
| `city_fully_eco_supply` | M4 与满足率一并算出，供 M9 使用 |
| `eco_cap_factor` | `1.0`（全环保）或 `0.8`（否则）；实现可缓存 |

### 环保身份 `is_eco`（按设施）

| 能源类型 | 默认 `is_eco` | 变为环保的条件 |
|----------|---------------|----------------|
| 风电 | **是** | — |
| 太阳能 | **是** | — |
| 水电 | **是** | — |
| 火电 | **否** | 研发 **环保火电** 类科技后，对机组 **升级** 完成（见下节） |
| 核电 | **否** | 研发 **环保核电** 类科技后，对机组 **升级** 完成 |

**设计意图**：

- 本市 **仅** 风/光/水，或火/核均已环保升级 → **全环保** → 社会价值可按 **`city_base` 的 100%** 潜力（再乘满足率）。
- 本市存在 **任意一台** 未升级火电/核电（哪怕闲置、哪怕满足率主要靠外电）→ **非全环保** → 社会价值 **最多** `city_base × 80%`（再乘满足率）。
- 本市无机组、100% 靠外电满供 → **全环保**（外电视同环保 + 本市无设施）。
- 后期鼓励：**联网受入** 超级水电/风光外送，同时 **拆除或不再新建** 本市高运维火电/核电（见下节「后期供能尺度」）。

环保升级 **不提高** 铭牌（除非另有 max 类科技）；主要改变 `is_eco` 与 **运营成本**（待表）。

### 示例

| 城市供能结构 | 满足率 | `city_fully_eco_supply` | 满供时社会价值潜力 |
|--------------|--------|-------------------------|-------------------|
| 仅风电，风能一般 | 100% | true | **100%** `city_base` |
| 100% 满足率，本市 1 台未升级火电（可闲置） | 100% | **false** | **80%** `city_base` |
| 100% 满足率，本市仅环保升级火电 | 100% | true | **100%** `city_base` |
| 100% 满足率，本市无机组、全靠外电（含邻市煤电） | 100% | **true**（外电视同环保） | **100%** `city_base` |
| 100% 满足率，本市有未升级核电 + 大量清洁外电 | 100% | **false**（本市有机组） | **80%** `city_base` |

## 首版能源类型

首版突出五类：**火电、水电、风电、太阳能、核电**。

每类在数值表统一暴露（实现字段名见 `balance-data-structure.md`）：

| 参数 | 说明 |
|------|------|
| 建设费用 / 工期 | 分期扣款见 [02-economy.md](./02-economy.md) |
| 月运营成本 | 受地区 `operation_cost_modifier`、`fossil_energy` 等影响 |
| 有效供能能力 | 额定出力 × 本章资源修正 |

**不在首版 GDD 展开**：机组级热效率曲线、燃料库存、弃风弃光详细仿真。

### 火电 `thermal`

| 项 | 规则 |
|----|------|
| 定位 | 前期易上量、运维可调；**默认非环保**（`is_eco = false`） |
| 环保路线 | 科技树 **环保火电** 节点（正式名称可更有设计感，见 `07-tech`）→ 研发后可对 **已完工** 火电机组 **升级**（工期 N 月，待表）→ 完成后 `is_eco = true` |
| 运维 | 环保升级后 **月运营成本上升**（倍率待表）；`fossil_energy` 地区标签仍只减运维，不改 `is_eco` |

### 水电 `hydro`

| 项 | 规则 |
|----|------|
| 环保 | **是**（`is_eco = true`） |
| 选址 | 仅 **近江河** 城市可建（地图章 T07 定槽位） |
| 常规 vs 超级 | **超级水电** 需 V 级科技；全图 **2** 座；单座策划尺度 ≈ **2 省** 体量联网供电、两座 ≈ **4 省**（各省 4–6 城不等，**不设**「每省 5 城」；MW 待精算，见下节） |

### 风电 `wind`

| 项 | 规则 |
|----|------|
| 环保 | **是** |
| 资源依赖 | 出力随地区 **风能标签** 修正（乘在铭牌上） |
| `wind_normal`（风能一般） | `resource_factor = **100%**`（×1.0） |
| `wind_rich`（风能丰富） | `resource_factor = **200%**`（×2.0） |
| 建设位 | 每城风能建设位上限（[05-map-and-slots.md](./05-map-and-slots.md)） |

```text
unit_wind = nominal_output × wind_region_factor × grid_factor × event_factor
// wind_region_factor: 一般 1.0，丰富 2.0
// nominal_output: 基础铭牌；若已做 max 升级则为升级后铭牌（×2，见下节）
```

建设界面与区域标签须 **明示** 本地风资源档位。

### 太阳能 `solar`

与风电 **同一套地区系数逻辑**（不做昼夜模拟）：

| 项 | 规则 |
|----|------|
| 环保 | **是**（`is_eco = true`） |
| `solar_normal`（光照一般） | `solar_region_factor = **100%**`（×1.0） |
| `solar_rich`（光照丰富） | `solar_region_factor = **200%**`（×2.0） |

```text
unit_solar = nominal_output × solar_region_factor × grid_factor × event_factor
// solar_region_factor: 一般 1.0，丰富 2.0
// nominal_output: 含 solar_max 升级后铭牌 ×2
```

建设页须明示光照资源档位；标签体系与风能、化石能源一致。

### 风光满配升级（`wind_max` / `solar_max`）

后期主力玩法：科技解锁后对 **已有** 风/光机组升级，提高铭牌而非改地区标签。

#### 科技树关系（原则）

| 节点 | 作用 |
|------|------|
| **储能设施**（科技） | 前置；与风能分支、太阳能分支 **分别交汇** |
| **`wind_max`** | 储能节点 + 风能分支汇合；研发完成后允许风电机组升级 |
| **`solar_max`** | 储能节点 + 太阳能分支汇合；研发完成后允许光伏机组升级 |

具体节点拓扑、前置与费用在 [07-tech.md](./07-tech.md) 规划；本章只约束 **玩法效果**。

#### 机组升级（玩家操作）

| 项 | 规则 |
|----|------|
| 前置 | 已研发对应 **`wind_max`** 或 **`solar_max`** |
| 对象 | 城内 **已完工** 的风电/光伏设施（逐台或批量由 Feature 定） |
| 工期 | **N 个月**（数值表配置，与建设类似按月推进） |
| 效果 | 升级完成后，该机组 **`nominal_output` 变为升级前的 2 倍** |
| 与地区系数 | 先定铭牌（含升级 ×2），再乘 `wind_region_factor` / `solar_region_factor` 等 |

**风电示例**（基础铭牌 100 MW，风能丰富区，已完成 `wind_max` 升级）：

```text
nominal_output = 200 MW
unit = 200 × 2.0（丰富）= 400 MW（再乘电网、事件）
```

**光伏示例**（基础铭牌 100 MW，光照丰富区，已完成 `solar_max` 升级）：

```text
nominal_output = 200 MW
unit = 200 × 2.0（丰富）= 400 MW（再乘电网、事件）
```

升级工期、升级费用（若有）进 `facility_config` / 升级专用表（T37）。

### 火/核环保升级（与风光 max 并列）

| 科技节点（工作名） | 研发后效果 |
|--------------------|------------|
| **环保火电** | 可对火电机组发起环保升级；完成后 `is_eco = true` |
| **环保核电** | 可对核电机组发起环保升级；完成后 `is_eco = true` |

规则与 `wind_max` 机组升级类似：**已完工机组**、**N 个月工期**、数值表配置；是否收费待表。节点 **显示名称** 在科技树文案中可另起更有设计感的名字。

### 核电 `nuclear`

| 项 | 规则 |
|----|------|
| 环保 | **默认否**（`is_eco = false`）；环保核电科技 + 机组升级后为 **是** |
| 解锁 | 公司 **IV 级** + 核电科技（[03-social-value.md](./03-social-value.md)） |
| 选址 | **省内中心大城市** 或 **都**（那座特大城本身） |
| 出力 | 按额定与电网规则计，无风/光式地区折减 |

## 后期供能尺度与玩家取舍（策划意图）

整体架构下，**火电、核电单城供能上限有限**，无法单靠火/核铺满全图；**全图绿色供能**依赖后期科技（风光 max、环保升级、**超级水电** + **电网调配**）。

| 阶段 | 玩家路径 |
|------|----------|
| 前期 | 火电等易上量；本市若留未升级火/核 → 社会价值 **80%** 上限 |
| 中期 | 区域风光、常规水电；开始 **拉电网** |
| 后期 | 全图 **2** 座超级水电（各约 **2 省** 联网体量）+ 主干/区域网；受电城可 **少建或不建** 本地火/核 |

**地图与尺度**：每省 **4–6** 个可经营节点、**逐省不同**（见 [03-social-value.md](./03-social-value.md)）。超级水电「能供几个省」取决于各省城数与需求配置，GDD **不写死**「10 城」或「每省 5 城」。

**火/核电运维**：维持成本 **显著偏高**；盈亏与取舍留给玩家在数值表里 **自己算账**（养不起则拆本地、吃外电）。

**电网玩法**：外电只抬 **满足率**；外电 **视同环保** + 仅判本市 → 鼓励「清洁基地外送 + 用电城拆掉本地煤电」。链接与损耗见 [06-grid.md](./06-grid.md)。

### 数值工作流（已决）

| 阶段 | 内容 |
|------|------|
| **当前（GDD）** | 只写 **定性思路**（谁强谁弱、量级关系、玩家取舍），便于架构定型 |
| **架构 locked 后** | 再 **精算** MW、造价、运维、门槛、超级水电出力等（`data/`、T37–T39）；可玩性依赖合理数值，不单靠公式 |

火/核装机上限、单城需求、`base_demand_mw` 等均在精算阶段与 [05-map-and-slots.md](./05-map-and-slots.md) 一并落表。

## 月度重算（M4）

| 项 | 规则 |
|----|------|
| 触发 | 每次 `下一月`，在 M1–M3 之后执行 |
| 范围 | 所有 **已解锁且可经营** 的城市（含都、区内各城） |
| 输出 | 每城 `demand_city`、`effective_supply_city`、`satisfaction_rate_city`、`city_fully_eco_supply` |
| 下游 | M5 收入可依赖满足率；M9 社会价值使用上述比率（[03-social-value.md](./03-social-value.md)） |

收入与需求的具体挂钩在 **经济/Feature** 层定义；本章保证 **M4 输出字段语义稳定**。

## 已决事项

| 议题 | 决策 |
|------|------|
| 核心指标 | 仅 **供能满足率**，无需求梯度 |
| 满足率封顶 | 供能 > 需求时按 **100%** |
| 计算粒度 | **按城市** |
| 能源类型 | 火电、水电、风电、太阳能、核电 |
| 风/光地区系数 | 一般 **100%**；丰富 **200%**（光伏与风电同逻辑） |
| 风光 max | 储能科技汇合风/光分支 → 铭牌 **×2** |
| 火/核环保 | 火电、核电 **默认非环保**；环保科技 + 机组升级 → `is_eco` |
| 天然环保 | 风、光、水 **始终** `is_eco` |
| 社会价值衔接 | **全环保** → 100% 潜力；否则 **上限 80%**（与满足率相乘） |
| 城市需求 | **仅静态配置表** `base_demand_mw` |
| 跨城供电 | 受入计入 **满足率**；外电 **视同环保**；环保仅判 **本市机组** |
| 省内城数 | 每省 **4–6** 节点，逐省配置（非固定 5 城） |
| 后期尺度 | 超级水电 ≈ **2 省/座**（定性）；数值 **架构后精算** |
| 100% 供能反馈 | 界面内提示，不弹全屏 |
