# 社会价值与公司等级

## 概述

**社会价值即公司等级进度**：没有单独的「经验值」；顶栏与升级共用 **`social_value_current`（当前社会价值）**。

- 每月 **M9** 按当下经营全盘 **重算** 社会价值（**可升可降**）。
- **M10** 若当前社会价值 ≥ **下一级门槛** → 公司升级；**等级只升不降**（已升的级不会因社会价值回落而掉级）。
- UI 让玩家一眼看懂：**现在社会价值多少 / 升到下一级还差多少**。

月度流程：**M4 供能重算 → M9 社会价值重算 → M10 升级检视**（[核心循环与时间](./01-core-loop.md)）。

**与旧稿差异**：已废止「供给 80% + 绿色 20%」**双轨分项**；现行用 **满足率 × 环保上限系数（0.8 / 1.0）** 单式表达（见「城市社会价值公式」）。公司界面 **不再** 展示金/绿两条分项进度条，改为 **按城一行** + 是否全环保。

---

## 唯一核心数值（实现）

**不保留** `company_experience`、`sv_snapshot_monthly` 等第二套字段。

| 字段 | 说明 |
|------|------|
| **`social_value_current`** | 公司 **当前社会价值**；顶栏显示；**等于**升级判定用的数值 |
| **`social_value_threshold_next`** | 当前等级 **升到下一级** 所需的社会价值门槛（配置表） |

M9 伪代码：

```text
social_value_current = Σ 各城 city_base × satisfaction_rate × eco_cap_factor
// eco_cap_factor: 全环保 1.0，否则 0.8；见下文
// 直接赋值，可小于上月结果
```

## 两种进度条（勿混淆）

### 1. 城市供能条（能量）

| 项 | 说明 |
|----|------|
| 位置 | `screen_city_detail` |
| 含义 | **当前供给 / 总需求**（如 `200/300`） |
| 变化 | 随时随设施、外来电、拆建 **浮动** |
| 作用 | 经营判断、**月收入**（见 [02-economy.md](./02-economy.md)） |

### 2. 社会价值与升级进度（公司）

| 项 | 说明 |
|----|------|
| 位置 | 顶栏 + `screen_company` |
| 当前值 | **`social_value_current`**（本月重算后的社会价值） |
| 升级条 | **`social_value_current / social_value_threshold_next`** |
| 文案示例 | 「社会价值 **3200** / **4500**（升至 III 级）」或进度条 + 「还差 **1300**」 |

```text
例：II 级公司，门槛 4500，本月经营下滑后重算为 2800
  → 显示 2800 / 4500，条变短，但仍是 II 级（等级不掉）
例：同上，下月经营好转重算为 4600
  → M10 升到 III 级，门槛改为升 IV 的值（如 12000），显示 4600 / 12000
```

| 规则 | 说明 |
|------|------|
| 社会价值可降 | 拆厂、供能变差 → 下月 M9 重算变低 → **升级条变短** |
| 等级不降 | 已到 III 级不会因社会价值跌破旧门槛而回到 II 级 |
| 与供能条 | **两套数**；玩家勿把 200/300 当成社会价值 |

公司界面按城展示 **供能满足** 与 **是否全环保**（或环保上限 80% 提示），与 **升级用社会价值总数** 并列（UI：T29）。

| 用途 | 说明 |
|------|------|
| **公司升级** | `social_value_current >= social_value_threshold_next` → M10 |

## 行政抽象（源于现实、扁平化）

大地图 ≈ 真实中国地图的 **扁平简化版**：**区** 是省（内有多城）；**都** 是 **不装在区里的大号单城**，与省 **同级点在地图上**。

| 游戏 | 现实类比 | 结构 |
|------|----------|------|
| **区** | 省 | **空壳容器**，内含 **6–8 个** 可经营行政节点（中心/常规/农村/边陲，**因省而异**；禁止全省统一模板） |
| **都** | 京沪级 **特大城** | 地图上 **一座大号城市**，**不属任何区**；与省节点 **平级**；建造位多于普通城 |
| **城市** | 省内各市/县；**都** 即那一座特大城本身 | 建设、供能、社会价值 **按城** |

牢记：**区 = 省壳（多城）**；**都 = 单座特大城，不是省壳**。点 **都** → **直接** 城市建设界面；点 **区** → 区域界面 → 某城（见 [01-core-loop.md](./01-core-loop.md)）。

### 省内节点数量（已决）

| 规则 | 说明 |
|------|------|
| 每省节点数 | **6–8 个** 浮动，由 `data/` **逐省** 配置（如 A 省 6 城、B 省 8 城） |
| 禁止 | 全图统一固定模板（如「每省同构 7 城」） |
| 结构不变 | 每省 **有且仅一个中心城市** + 若干常规/农村/边陲节点 |
| 全图城数 | ≈ Σ(各省 6–8) + **2 都**（都各算 1 城）；具体清单在 [05-map-and-slots.md](./05-map-and-slots.md)（T07） |

## 全图与公司等级 I–V

| 项 | 规则 |
|----|------|
| 全图 | **2 都 + 8 区**（10 个大地图节点：8 省 + 2 独立特大城）；跨区主干连接 **都/区** 对应节点 |
| 连通 | 各等级 **可经营** 省/都 在 **网状邻接** 上须为 **单一连通块**（见 [05-map-and-slots.md](./05-map-and-slots.md#可经营区必须大地图相连已决)） |
| 未解锁 | 灰显不可点 |
| I | 入门 **`CITY-START`**（`MAP-01` 中心城）；同省其它城只读 |

| 等级 | 可经营（累计） | 本档新开放（占位，见 [05-map-and-slots.md](./05-map-and-slots.md)） |
|------|----------------|--------------------------------------------------------|
| **I** | 1 城市 | `CITY-START` |
| **II** | 1 省壳全境 | `MAP-01` |
| **III** | **1 都 + 2 省壳** | `MET-A` + `MAP-02` |
| **IV** | **1 都 + 5 省壳** | `MAP-03`～`MAP-05` |
| **V** | 2 都 + 8 省壳 | `MET-B` + `MAP-06`～`MAP-08` |

各档可经营节点须在 **网状邻接** 上保持 **单一连通块**；换解锁顺序须同步改邻接表（见 05-map）。

## 每月重算（M9）

**定稿**：

1. M4 完成后，对 **已解锁、可经营** 的 **每一座「城市」** 计算当月社会价值（见下「哪些算城市」）。
2. **`social_value_current` = 所有这类城市社会价值之和**。

**哪些算「一座城市」**：

| 来源 | 计数 |
|------|------|
| 某 **区** 内 | 区内 **每一座** 可操作城市各算 1 座（含中心城、农村点等） |
| 某 **都** | **都本身只算 1 座城**（特大城单节点，不按多城拆分） |
3. 结果 **直接写入** `social_value_current`（**覆盖**，可升可降）。
4. 供能变差 → 某城贡献下降 → 总和 **可能减少**。

| 对比 | 社会价值 | 资金收入 |
|------|----------|----------|
| 供能回落 | M9 重算 **可能变低** | 月收入 **下降** |
| 公司等级 | **不变**（只升不降） | — |

### 升级判定（M10）

```text
当 social_value_current >= social_value_threshold_next（当前等级配置）:
    公司等级 +1
    social_value_current 保持不变（不扣门槛、不清零）
    读取新等级的 social_value_threshold_next 作为 UI 分母
```

可一次连升多级（实现见 T13）。

**策划意图**：`social_value_threshold_next` 通常 **低于** 该档已解锁地图的理论社会价值满额，使玩家 **高比例经营** 即可升级，**不必 100%**（比例在数值表按档调，非固定 80%）。

**升级门槛（示例，待 `company_level_thresholds` 精算）**：

| 当前等级 | 升下一级 | `social_value_threshold_next`（示例） |
|----------|----------|--------------------------------------|
| I | II | 500 |
| II | III | 4500 |
| III | IV | 12000 |
| IV | V | 35000 |

门槛宜 **低于** 该档已解锁地图的 **理论满额**（各城 `city_base` 之和），使玩家 **高比例经营** 即可升级，**不必** 全图满供。

## 城市社会价值公式（按城市）

每个 **城市** 配置 `city_base_social_value`（数值表 `data/`，T07 与 region 表对齐）。

**已废止**：原「80% 供给 + 20% 绿色 × 清洁占比」双轨公式。

### 现行公式

```text
eco_cap_factor_city = 1.0   if city_fully_eco_supply else 0.8

green_pr_mult = 1.05   if eng_green_pr lit AND city_fully_eco_supply else 1.0
                     // 见 07-tech；仅全环保城生效

city_sv_monthly = city_base_social_value
                × satisfaction_rate_city
                × eco_cap_factor_city
                × green_pr_mult

// 每城结算后取整，再求和
city_sv_monthly_int = (city_sv_monthly 按配置 num/den 乘算后) // den 分母取整

social_value_current = Σ_{each unlocked operable city} city_sv_monthly_int   // M9，覆盖写入
```

| 因子 | 来源 |
|------|------|
| `satisfaction_rate_city` | M4 供能满足率（[04-energy-supply.md](./04-energy-supply.md)） |
| `city_fully_eco_supply` | M4：本市设施均 `is_eco`；**外电视同环保**、不追溯（见 [04-energy-supply.md](./04-energy-supply.md)） |

### 环保上限规则（核心）

| 条件 | `eco_cap_factor` | 满供时该城社会价值 |
|------|------------------|-------------------|
| **全环保**（本市仅风/光/水，或火/核均已环保升级；或无本市机组） | **1.0** | **100%** × `city_base` |
| **本市存在任意非环保机组**（含 1 台未升级火电/核电） | **0.8** | **最多 80%** × `city_base` |

说明：

- **供能 100% 但有一台未升级火电/核电** → 满足率 1.0，但 `eco_cap_factor = 0.8` → 该城只得 **`city_base × 80%`**。
- **纯风/光/水即可满供**，或 **无本市机组、靠外电满供** → 全环保 → **`city_base × 100%`**（满足率 100% 时）。
- 环保升级 **不替代** 供能建设；两维独立：**盖得多**（满足率）与 **盖得绿**（本市机组是否全环保；外电视同环保）。
- **后期**：超级水电（单座约 **2 省体量**，随各省 6–8 城浮动）+ 电网外送；具体 MW **待架构定型后精算**（见 [04-energy-supply.md](./04-energy-supply.md)）。

### 与旧设计的对照

| 旧规则 | 新规则 |
|--------|--------|
| 清洁占比折 20% 绿色条 | 取消；改为 **0.8 / 1.0 全城系数** |
| 核电默认算清洁 | 核电 **默认非环保**，**`eco_nuclear`** 研发完成 → 已完工机组 **自动** 环保化 |
| 火电靠环保模块 | **`eco_thermal`** 研发完成 → 已完工火电 **自动** 环保化，与风光 max 同级思路 |

公司界面明细：省内 **按城列表**；**都** 单行；展示建议含「本月社会价值 / 满额潜力」「是否全环保」。

## 扣减与波动

**不做** 独立的「社会价值扣减事件」或第二套累计经验；**扣减** 仅指 **M9 重算后 `social_value_current` 变低**。

| 触发 | 效果 |
|------|------|
| 供能满足率下降 | 该城 `× satisfaction_rate` 变小 → 总和可能减少 |
| 新建未环保火电/核电 | `eco_cap_factor` 变 **0.8** → 该城上限降低 |
| 拆除环保机组、遗留非环保机组 | 可能失去全环保 → **0.8** 上限 |
| 解锁新城但暂未满供 | 分子增加但单项贡献低 → 总和可能暂时下降 |

| 对比 | 说明 |
|------|------|
| vs 资金 | 收入随 **当月** 供能；社会价值亦 **当月快照**，非历史累加 |
| vs 公司等级 | 社会价值可降；**等级 I–V 不回退** |
| vs 事件 | 事件 **不** 直接改 `social_value_current`（见 [08-events.md](./08-events.md)） |

## 环保身份（摘要）

设施 `is_eco` 定义见 [04-energy-supply.md](./04-energy-supply.md#环保供能判定社会价值用)：

| 类型 | 默认 |
|------|------|
| 风、光、水 | 环保 |
| 火电、核电 | 非环保 → 环保科技 + 机组升级后为环保 |

## 战略工程、科技与等级

| 等级 | 解锁 |
|------|------|
| **III** | `nuclear_1` 点亮后可建核电；选址 **省内中心大城市** 或 **都** |
| **IV** | 无害化核废料 → 核电 ECO |
| **V** | 超级水电科技；全图 **2** 座槽位；单座策划尺度约 **2 省** 联网用电、两座约 **4 省**（非固定「10 城」；随各省 6–8 节点浮动，**精算在 data 阶段**） |

常规水电：近江河城市可建。超级水电经主干向多城/省输送。线损见 [06-grid.md](./06-grid.md)（单条区域 = 普通城需求 **÷4**，单条主干 = 普通城需求 **全额**；普通城需求 = 中心 **1/3～1/2**）。

## 已决事项

| 议题 | 决策 |
|------|------|
| 经验 vs 社会价值 | **合并**；仅 `social_value_current` |
| 每月更新 | M9 **按城市算后求和**，覆盖写入，可增可减 |
| 升级 | 社会价值 ≥ 门槛 → 升级；等级 **只升不降** |
| 区 | **省壳**，社会价值 = 其内 **各城之和** |
| 都 | **单座特大城**，社会价值 = **该城 1 条** |
| M9 汇总 | **每个城市社会价值求和** |
| 社会价值公式 | `city_base × 满足率 × (全环保 1.0 / 否则 0.8)` |
| 火/核 | 默认非环保；环保科技 + 机组升级 |
| 环保范围 | **仅本市机组**；**外电视同环保**；不追溯、外送不连带 |
| 省内城数 | 每省 **6–8** 节点，逐省配置，禁止全图同构模板 |
| 数值阶段 | GDD 仅定性尺度；**整数表** 在 data 层 T37 精算 |
| 公式形态 | **废止** 80/20 双轨；**现行** 满足率 × 环保系数 |
| `eng_green_pr` | 全环保城 **×1.05**（[07-tech.md](./07-tech.md)） |
