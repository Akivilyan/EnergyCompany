# v0 实现里程碑任务拆条

## 1. 目标与使用方式

本文将 T45 落地为**可逐对话执行**的编码任务清单，默认每次对话完成 1 个最小可验收任务。

使用规则：

- 先做 P0（必须）再做 P1（增强）；
- 每个任务都包含「输出物 + 完成定义 + 验证方式」；
- 若任务阻塞超过 1 次对话，拆成更小子任务继续推进。

---

## 2. 里程碑总览（M0-M8）

| 里程碑 | 目标 | 对应 T41 体验点 | 建议对话数 |
|--------|------|------------------|------------|
| M0 | 工程骨架可运行 | E2 基础 | 1 |
| M1 | 模拟核心最小闭环 | E2 | 2-3 |
| M2 | 月结关键步骤可测 | E2/E6 | 2-3 |
| M3 | 城市主流程联调 | E2 | 2 |
| M4 | 等级与区域解锁 | E3/E4 | 2 |
| M5 | 科技与灾害轴 | E3/E5 | 2-3 |
| M6 | 公司经营与终局 | E6 | 2 |
| M7 | 新手与主流程收口 | E1 | 2 |
| M8 | 平台收尾与回归 | E1-E6 | 2 |

## 3. P0 必做任务（可直接开工）

## 3.1 M0 工程骨架

### T45-01 建立目录与边界护栏

- 输出物：
  - `src/app`, `src/ui`, `src/modules`, `src/sim`, `src/config`, `src/infra`, `tests/sim` 空骨架；
  - lint 规则：禁止 `src/sim` 引用引擎 API。
- 完成定义：
  - 项目可启动，lint 通过，边界违规可被检测。
- 验证：
  - 运行 lint；手动构造一次违规导入并确认报错。

### T45-02 ConfigRepo 最小实现

- 输出物：
  - `ConfigRepo` 接口与 JSON 加载器；
  - `config/generated` 最小样例表读取通路。
- 完成定义：
  - 可通过 `id` 查询城市、设施、等级阈值与 run_config。
- 验证：
  - 单测覆盖查询命中/缺失分支。

## 3.2 M1 核心状态与命令入口

### T45-03 `GameState` 与初始化

- 输出物：
  - `GameState` 类型与 `createInitialState(runOptions)`；
  - 初始化支持 `tech + simple + tutorial` 三种关键入口。
- 完成定义：
  - 可生成一局合法初始状态，含版本号与关键索引结构。
- 验证：
  - 单测断言初始资金、月份、phase、ads 次数等字段。

### T45-04 `dispatch` 基础框架

- 输出物：
  - `dispatch()` 主入口与 `SimResult`；
  - 标准错误码返回路径。
- 完成定义：
  - 支持至少 3 个命令：`queue_construction`、`start_research`、`apply_loan`。
- 验证：
  - 命令成功/失败原子性单测（state 前后哈希）。

## 3.3 M2 月结主流程

### T45-05 `settleNextMonth` 骨架（M1-M14）

- 输出物：
  - 固定 M1→M14 执行管道；
  - `SettlementReport` 结构化输出。
- 完成定义：
  - 空实现下也能产出 14 步报告并推进月份。
- 验证：
  - 单测断言 step 顺序与数量固定。

### T45-06 落地 M4（供能重算）

- 输出物：
  - 并网岛计算与城市满足率、净受入、环保上限因子。
- 完成定义：
  - 与 `features/supply-calculation.md` 的字段语义一致。
- 验证：
  - 三组快照：孤城、双城并网不足、全环保城市。

### T45-07 落地 M9/M10/M13/M14

- 输出物：
  - 社会价值覆盖写入；
  - 升级只升不降；
  - 破产/通关终局切换。
- 完成定义：
  - 关键终局路径可由测试稳定复现。
- 验证：
  - 单月连升、连续负资金、86 月通关三组用例。

## 3.4 M3-M4 主流程联调

### T45-08 `modules` 命令编排层

- 输出物：
  - `runCommand()` 与 `runNextMonth()`；
  - `modules -> sim` 调用统一入口。
- 完成定义：
  - UI 不直接触碰 `sim` 内部对象。
- 验证：
  - 契约测试：扫描 UI 层无 `sim/core` 直连。

### T45-09 城市页最小闭环（建造 + 推月）

- 输出物：
  - `screen_city_detail`：建造、下一月、资源变化展示。
- 完成定义：
  - 玩家能完成单城建造并看到供能/SV变化。
- 验证：
  - 手动冒烟：新局 3 次推进无报错。

### T45-10 等级解锁与 region 流程

- 输出物：
  - M10 升级后 unlock 生效；
  - `screen_region` 可进入并完成区域铺线最小动作。
- 完成定义：
  - II 级可进 MAP-01 全省并完成 1 条区内链路。
- 验证：
  - 冒烟 + 回归脚本检查 unlock 条件。

## 3.5 M5-M6 科技、灾害、经营、终局

### T45-11 科技树单队列

- 输出物：
  - II 级入口、单队列研发、取消返还；
  - 点亮效果在次月结算生效。
- 完成定义：
  - 至少 1 次从 researching 到 lit 的完整链路。
- 验证：
  - 单测 + UI 冒烟。

### T45-12 固定灾害轴与事件面板

- 输出物：
  - 22/41/63/86 月固定灾害触发；
  - `panel_events` + 全屏灾害弹窗。
- 完成定义：
  - 可稳定触发首场灾害并影响经营指标。
- 验证：
  - 快照测试锁定 22 月输出。

### T45-13 公司屏、借贷、终局页

- 输出物：
  - `screen_company`：快照、近月流水、单笔借贷；
  - `screen_run_result`：victory/bankrupt。
- 完成定义：
  - 破产与通关都可进入结算页且不可继续运行态命令。
- 验证：
  - 双分支冒烟。

## 3.6 M7-M8 新手、平台、回归

### T45-14 教学局与引导遮罩

- 输出物：
  - 教学方针开局、步骤推进、跳过；
  - `tutorial_doctrine_cleared` 存档标记。
- 完成定义：
  - 教学可走完也可跳过，不阻塞正式局。
- 验证：
  - 首次/二次开局流程回归。

### T45-15 存档与恢复

- 输出物：
  - `serialize/deserialize` 接入 `infra/storage`；
  - 版本校验与异常保护。
- 完成定义：
  - 退出重进后可继续同一局。
- 验证：
  - 手动重启 + 自动化反序列化测试。

### T45-16 广告 stub 与全链路回归

- 输出物：
  - `claim_ad_reward` stub 完成；
  - E1-E6 验收回归脚本。
- 完成定义：
  - 在无真实 SDK 下可跑通完整 v0 体验链。
- 验证：
  - 回归报告输出通过率与失败案例。

## 5. 每次对话执行模板

建议后续编码对话按以下模板固定：

1. 选定 1 个任务 ID（例如 `T45-06`）。  
2. 实现代码 + 单测。  
3. 本地验证（lint/test/冒烟）并记录结果。  
4. 更新本文件任务状态（未开始 -> 完成）。  
5. 在必要节点提交并推送。  

---

## 6. 风险与止损策略

| 风险 | 信号 | 止损动作 |
|------|------|----------|
| 核心接口频繁返工 | 单周内修改 `GameState` 结构 >2 次 | 先冻结接口，新增扩展字段而非重构主结构 |
| UI 侵入核心 | UI 直接改 state | 增加 lint + code review 阻断 |
| 数值回归不可定位 | 同局不同结果 | 强制 `seed` + SettlementReport 快照 |
| 任务过大拖慢推进 | 单任务跨 2+ 对话 | 立即再拆分并重排优先级 |
