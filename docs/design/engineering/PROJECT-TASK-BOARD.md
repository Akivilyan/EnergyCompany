本文件只回答“当前在干什么、下一步做什么”。执行流水、验证记录与版本记录由 Git 历史和提交说明承接；更早历史见 `archive/project-task-board-history.md` 与 Git 历史。

## 1. 当前阶段

- 当前阶段：`FAST-01` Playable Demo 快线
- 当前策略：采用快线批次节奏，冻结非阻塞小问题、模糊数据精磨和 HUD 细节闭环；先推进到较大的可玩/可验节点，再集中验证
- 当前重点：正式 UI / Prefab 样张与资产规范批次推进中；城市页背景、设施、电网、状态、UI 面板与图标层命名及静态护栏持续固化，广告 SDK 后置

## 2. 当前任务

- 任务 ID：`FAST-01`
- 标题：Playable Demo 快线落地（从 v0 最小裁剪闭环推进到更完整、可持续试玩的 demo）
- 状态：`doing`
- 开始时间：2026-06-18
- 完成定义：
  - 不再被真机/微信工具的小问题阻塞主线
  - 完成真正可玩的 demo：地图扩张、公司等级、科技主干与分支、灾害轴、经营压力、终局路径均可体验
  - 数据允许粗糙可调，不因设计数值含糊而停在局部精磨
  - 形成后续收敛批次：正式 UI、广告 SDK、数值平衡、提示精修

## 4. 下一步

1. 保持 FAST-01 路线矩阵常绿：`sim:playtest-bundle` 作为完整 demo 回归入口
2. 正式 UI / Prefab 批次：先固化 UI 美术与音频方向，再做城市页可玩 UI 样张
3. 资产拆分批次：围绕城市页拆背景、建筑、电网、光效、UI 面板与图标层
4. 数值收敛批次：围绕公司 I-V、灾害、终局和路线耗时做粗调，不做无边界精磨
5. 提示精修批次：收敛经营压力、科技解法、灾害备考/恢复和终局反馈文案
6. 广告 SDK 批次：广告放在后置阶段，最后再收口微信激励广告真机链路
