# 项目级任务看板

本文件只回答“当前在干什么、下一步做什么”。执行流水、验证记录与版本记录由 Git 历史和提交说明承接；更早历史见 `archive/project-task-board-history.md` 与 Git 历史。

## 1. 当前阶段

- 当前阶段：`FAST-01` Playable Demo 快线
- 当前策略：冻结非阻塞小问题、模糊数据精磨和 HUD 细节闭环，把开发重心钉死在真正可玩的完整 demo
- 当前重点：主要玩法完整、分支玩法健全；允许粗糙，不允许只剩主线壳层

## 2. 当前任务

- 任务 ID：`FAST-01`
- 标题：Playable Demo 快线落地（从 v0 最小裁剪闭环推进到更完整、可持续试玩的 demo）
- 状态：`doing`
- 开始时间：2026-06-18
- 完成定义：
  - 不再被真机/微信工具的小问题阻塞主线
  - 完成真正可玩的 demo：地图扩张、公司等级、科技主干与分支、灾害轴、经营压力、终局路径均可体验
  - 数据允许粗糙可调，不因设计数值含糊而停在局部精磨
  - 形成后续收敛批次：正式 UI、广告 SDK、数值平衡、提示精修

## 4. 下一步

1. 固定 demo 验收路线：从开局到终局的一条完整试玩路径
2. 地图/区域扩张可玩化：不止解锁，要能连续跨区建设、铺线、选择目标
3. 城市建设分支补全：让风/光/火/水/核等建设选择在中后期仍有作用
4. 公司 I～V 级推进贯通：等级提升、解锁内容、资金压力、区域扩张形成节奏
5. 科技主干与分支可玩化：35 个节点不只显示，要能影响建设、成本、供能、风险
6. 灾害/经营压力可反制：4 场灾害要形成“准备-冲击-恢复”的玩法，而不只是弹窗
7. 终局路线跑通：`MET-B` / 超级水电 / 最终灾害 / 胜负结算形成完整结尾
