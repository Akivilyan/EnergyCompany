# 项目状态与任务看板

本文件只记录当前产品状态、当前模块和下一步。长期顺序见 `DEVELOPMENT-STRATEGY.md`，协作规则见根目录 `AGENTS.md`，历史查 Git。

## 当前产品状态

- 平台与技术：微信小游戏，Cocos Creator 3.8.8 + TypeScript。
- 规则基础：`src/sim/` 是规则真理源；`src/modules/` 提供业务编排和玩家动作入口。
- 设计基础：城市视觉方向、正式图标、风电/光伏/火电代表建筑和城市建设浏览器设计原型均已保留。
- 客户端状态：正式 Cocos 城市场景已可完成建设、月结、I → II 公司升级，并从已刷新入口走通火电·II 研发、单队列等待、节点点亮、既有设施 tier I → II 与城市供能 220 → 440 MW；两档目标尺寸玩家证据已保留。
- 开发方式：按七个玩家垂直切片顺序推进；每次只完成一条真实操作流程，不同时铺开后续页面和资产。

公司达到 III 级并点亮 `grid_regional` → 进入区域 → 选择两座城市 → 建设区域线 → 完工 → 查看供能调剂。

### 范围

- 只交付一个代表性区域内两城选点、区域线建设、完工和供能调剂路线。
- 并网岛内按相同满足率、按需求比例分配可用电力；固定线损先扣除，在建链路不参与供能。

### 不做

- 不进入跨区主干、全国地图、灾害、失败或超级水电切片。
- 不铺完整区域地图、多区域经营或完整电网管理系统。

### 验收

- Cocos 中一条真实路线可从已开放区域入口选择两城、建设区域线、等待完工并看到供能调剂。
- 明确展示建链门槛、成本、工期、线损、在建不生效和完工后的分配原因；规则与模块口径一致。
- 自动验证按 `AGENTS.md` 执行，并保留目标尺寸截图与真实点击证据。
