# 项目状态与任务看板

本文件只记录当前产品状态、当前模块和下一步。长期顺序见 `DEVELOPMENT-STRATEGY.md`，协作规则见根目录 `AGENTS.md`，历史查 Git。

## 当前产品状态

- 平台与技术：微信小游戏，Cocos Creator 3.8.8 + TypeScript。
- 规则基础：`src/sim/` 是规则真理源；`src/modules/` 提供业务编排和玩家动作入口。
- 设计基础：城市视觉方向、正式图标、风电/光伏/火电代表建筑和城市建设浏览器设计原型均已保留。
- 客户端状态：正式 Cocos 城市场景已可完成建设、月结、公司升级和火电·II 研发，并从 III 级且已点亮区域电网的入口走通两城选点、扣款建线、在建等待和并网调剂；固定线损、统一满足率与按需求分配均有两档目标尺寸玩家证据。
- 开发方式：按七个玩家垂直切片顺序推进；每次只完成一条真实操作流程，不同时铺开后续页面和资产。

## 下一步

- 模块：`PLAYABLE-CORE-05`
- 标题：事件、灾害与失败
- 状态：`pending`

### 目标

收到固定灾害预警 → 准备资金、建设或研发 → 灾害激活 → 查看即时与持续效果 → 应对并恢复，或连续两个月月末资金为负而破产。

### 输入

- `docs/design/engineering/DEVELOPMENT-STRATEGY.md`
- `docs/design/ui/city-flow-gameplay-contract.md`
- `docs/design/ui/events.md`
- `docs/design/ui/month-settlement-flow.md`
- `docs/design/features/events.md`
- `docs/design/data/schemas/events-and-campaign.md`

### 范围

- 只交付固定灾害轴中的一个代表性预警、激活、持续压力、恢复或破产路线。
- 灾害反馈回答发生了什么、立即影响和持续多久；连续两个月月末负资金才进入破产。

### 不做

- 不接完整随机 policy / market 事件池，不制作事件选择分支或灾害场景变体。
- 不进入全国地图、跨区主干、超级水电或终局能力切片。

### 验收

- Cocos 中一条真实路线可从灾害预警进入准备阶段，在激活后看懂即时扣款、持续效果与剩余月份，并能经营到恢复或连续负资金破产。
- 全屏反馈只做确认已读，不伪装成策略选择；返回城市后事件入口继续显示活跃压力，规则与模块口径一致。
- 自动验证按 `AGENTS.md` 执行，并保留目标尺寸截图与真实点击证据。
