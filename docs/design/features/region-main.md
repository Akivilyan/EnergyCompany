# 地区主界面

## 1. 目标

`screen_region` 用于单一区域内的选城、区域内组网和进入城市建设，不承担跨区主干或城内建造细节。

## 2. 输入与入口

| 入口 | 条件 | 结果 |
|------|------|------|
| `screen_world_map` 点击 `MAP-xx` | 区域已解锁 | 进入 `screen_region` |
| `screen_city_detail` 返回 | 当前城市属于某区域 | 返回该区域 |
| 教学流程跳转 | 当前步骤允许 | 进入指定区域 |

补充：

- `MET-A/B` 不经过本界面
- 未解锁区域不可进入

## 3. 玩家操作

### 选城

- 点击可操作城市：进入 `screen_city_detail`
- 点击只读城市：只显示摘要，不开放建设命令

### 区域内建线

1. 选择同一区域内两座城市
2. 提交 `queue_grid_link`
3. 校验通过后进入施工队列，等待 M2 推进

### 推月

- 本界面不是默认 `下一月` 主入口
- 若从全局入口触发推月，按统一月结流程执行

## 4. 系统行为与副作用

| 行为 | 副作用 |
|------|--------|
| 进入区域界面 | 刷新区域上下文、城市状态、链路状态 |
| 进入城市 | 更新 `current_city_id` |
| 下达区域线建设 | 扣费、入队、记录工期 |
| 区域解锁变化后再次进入 | 依据当前等级刷新节点状态 |

## 5. 与月结的关系

| 步骤 | 关系 |
|------|------|
| M2 | 区域线施工推进与完工 |
| M4 | 连通关系影响供能结果 |
| M9 | 本区城市贡献汇总进公司 SV |
| M10 | 升级可能改变区域可操作范围 |

## 6. 错误与边界

| 场景 | 处理 |
|------|------|
| 未解锁区域进入 | 拒绝 |
| 跨区域建线 | 拒绝 |
| 资金不足 | 拒绝 |
| 结算中操作 | 拒绝 |
| 只读城市尝试建设 | 不显示建设动作 |

## 7. 验收

- 已解锁区域可正常进入并展示区域内节点
- 可操作城市能进入城市界面
- 跨区建线会被拒绝
- 区域线在 M2 正确推进并生效
- 升级后重新进入区域时，节点状态按最新等级刷新
