## 维护约定

- **何时写**：对主设计稿有**实质性**修订时（新增/删减系统、改循环或资源规则、改地图结构、改胜负边界等）。
- **建议每条包含**：
  - **日期**（YYYY-MM-DD）
  - **摘要**：改了什么（一两句话）
  - **动因**：为何改（可选，简短）
  - **备注**：若与摘要文档不同步、或留待验证的假设，可一句带过
