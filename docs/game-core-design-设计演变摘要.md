- `2026-05-14`：**玩法瘦身与节拍调整**（与策划讨论稿对齐，已写入主文档）。**摘要**：去掉成就系统；去掉竞争公司与区域争夺，起伏改由类《大理石时代》的**事件**承担，并收敛事件首版作用维度为资金投入、资金收入、研发加快/减慢（可少量扩展）；社会价值改为**按月结算**（与供能覆盖挂钩），允许因拆除等导致扣减，**公司等级只升不降**且与等级检视同放月度；**可经营区域随公司等级分批解锁**（例：1 级 1 区、2 级 +2 区、3 级 +2 区 + 1 超大都市）；商业化改为**首发仅广告**，后续版本仅 **6 元财务总监** 与 **30 元技术总监+去广告** 两档一次性买断，取消抽卡与多档礼包；主文档结论处明确**核心定稿后再做技术选型**。**动因**：控制小游戏复杂度、扩大潜在受众，同时用月度社会价值/等级与分区解锁缓解「前几分钟后劲不足」与单调感。**备注**：`[game-core-design-整合摘要.md](./game-core-design-整合摘要.md)` 已同步。
